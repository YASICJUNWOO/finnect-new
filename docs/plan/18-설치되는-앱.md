`web/` 에 **설치와 관련된 것이 하나도 없었다.** 매니페스트도 아이콘도 `web/public/` 조차 없어서, 탭에 기본 문서 아이콘이 떴고 홈 화면에 얹을 방법이 없었다.

**반응형은 이미 있었다.** `@media (max-width: 640px)` 가 아홉 곳에 있다. 없던 것은 그 위의 한 겹 — 매니페스트, 아이콘, 안전영역, 그리고 **좁은 화면에서 손에 닿는 내비**다.

## 태스크

### T-0079 앱 마크

`tools/make-icons.py`. **궤도(S7)를 줄인다** — 중심 하나 · 위성 셋 · 끊긴 고리 · 살 셋. 기하는 `Orbit.tsx` 와 [ADR-0017](../adr/0017-위키-그래프-궤도-배치.md)에서 온다.

단색이다. `--ink` 바탕에 흰 마크뿐이고 **노드 분류색을 안 쓴다** — `DESIGN.md` §3-7 이 색을 궤도와 문서 빈칸에만 몰아 쓰라고 했다.

PNG 를 **거리장으로 직접 칠하고 zlib 으로 조립한다.** 이 서버에 PIL·cairosvg·ImageMagick 이 없고 `sharp` 를 `web/` 에 넣지 않는다(ADR-0039 결정 4). SVG 도 같은 스크립트가 낸다 — 좌표를 두 곳에 두지 않는다.

**모서리 때문에 두 벌이다.** `maskable` 은 OS 가 깎으니 각지고, **`any` 는 아무도 안 깎으니** 파비콘과 같은 반경 22% 로 둥글다(RGBA). 각진 것을 `any` 에 주면 크롬 설치 창에서 앱 아이콘만 검은 네모가 된다.

낸 것: `web/public/icon-192.png`·`icon-512.png`(둥근 · any) · `icon-192-maskable.png`·`icon-512-maskable.png`(각진) · `web/app/apple-icon.png` · `web/app/icon.svg`

### T-0080 매니페스트

`web/app/manifest.ts`. `display: standalone` · `scope: /` · 아이콘 넷.

`theme_color` 는 `--surface`(상단 막대와 같은 색), `background_color` 는 `--canvas`(페이지 바탕). **뜻이 다르니 값도 다르다.**

아이콘은 **같은 파일을 `any` 와 `maskable` 로 두 번 적는다.** 웹 표준은 `"any maskable"` 을 허용하지만 Next 의 타입이 값 하나만 받는다(`manifest-types.d.ts`).

### T-0081 안전영역과 iOS

`web/app/layout.tsx`. `viewport.viewportFit = "cover"` · `themeColor` · `appleWebApp`.

**`viewportFit` 이 이 태스크의 요점이다.** 없으면 `env(safe-area-inset-*)` 이 전부 0 이라, CSS 를 적어 둬도 조용히 아무 일도 안 일어난다.

`other: { "apple-mobile-web-app-capable": "yes" }` 를 손으로 더했다. **Next 는 접두사 없는 최신 이름만 낸다** — iOS 17.4 아래는 옛 이름만 알고, 없으면 홈 화면에서 열어도 크롬이 그대로 있는 창으로 뜬다.

### T-0082 하단 탭 바

`web/app/(product)/layout.tsx` + `.module.css`. 640px 아래에서 상단 `.menu` 를 숨기고 하단 `.tabs` 를 켠다.

**축을 배열 하나(`AXES`)에 두고 위아래가 같이 읽는다.** 두 곳에 적으면 넷째 축이 생기는 날 한쪽만 고쳐진다.

`.bar` 는 위 안전영역을, `.tabs` 는 아래 안전영역을 **안쪽 여백으로** 먹는다 — 흰 면이 그만큼 늘어나야 노치·홈 인디케이터 밑이 비지 않는다. `.main` 은 `--s8 + 56px + 아래 안전영역` 만큼 아래를 비운다.

### T-0084 디자인 리뷰가 찾은 것을 고친다

`omd-designer-review` 가 **BLOCK 하나와 WARN 일곱**을 냈다. BLOCK 은 이 작업이 만든 회귀다.

| | 무엇 | 고친 것 |
|---|---|---|
| **BLOCK** | `viewportFit: "cover"` 가 `admin/` 에도 가는데 거기 안전영역 보정이 **0곳**이었다 | `admin/layout.module.css` — ADR-0039 결정 5 |
| WARN | `install()` 에 `try/finally` 가 없어서 `prompt()` 가 거부하면 **못 쓰는 `설치` 버튼이 남는다**(§12.4 위반) | `finally` |
| WARN | 하단 탭 바에 `:hover` 가 없다 — 641px 에서 되던 것이 640px 에서 안 된다 | 선택자 둘 |
| WARN | 포커스 링이 뷰포트 아래 끝에 **잘린다**(§3-9) | `--tabbar-pad` 8px 바닥 |
| WARN | `--ink-3` 2.84:1 — 새 자리 셋 | 둘은 `--ink-2`, 하나는 열린 질문(§12.5) |
| WARN | 상태 막대 색 리터럴이 **세 곳**인데 주석이 '두 곳'이라 적었다 | 주석 + §12.3 |
| WARN | `any` 아이콘이 각져서 파비콘과 갈린다 | 둥근 벌을 따로 낸다 (T-0079) |

FYI 여섯 중 셋을 같이 고쳤다 — `appinstalled` 리스너(크롬 ⋮ 메뉴로 설치하면 막대가 계속 권했다) · `56px` 중복을 `--tabbar-h` 로 · `.go` 줄 높이.

**안 고친 것**: 하단 탭 바의 `--ink-3`. 상단이 전부터 그 색이라 한쪽만 올리면 640/641px 에서 같은 메뉴가 다른 색이 된다 — `--ink-3` 의 역할을 정하는 §4.1·§8.2 결정이 먼저다(§12.5).

### T-0083 설치 권유 — **2026-08-22 되돌렸다**([ADR-0051](../adr/0051-설치-권유-띠를-없앤다.md))

**아래는 지워진 코드의 기록이다.** `Install.tsx` 와 `.module.css` 는 없다. 띠가 제품 첫 화면에서 공고보다 먼저 보이는 자리를 한 줄 쓰고 있었고, 파는 것이 「닿는 거리」 하나였다. **설치 자체는 그대로 된다** — 매니페스트가 살아 있어 브라우저 메뉴로 얹힌다.

`web/components/Install.tsx` + `.module.css`. 길이 둘이다 — 크롬은 `beforeinstallprompt`, **iOS 사파리는 그 이벤트를 안 줘서 방법을 글로 적는다.**

갈림길을 **UA 로 판정하지 않는다.** `navigator.standalone` 이 iOS 사파리에만 있는 속성이라 그 존재를 본다.

`useSyncExternalStore` 를 쓴다. `useEffect` + `setState` 로 브라우저 능력을 읽으면 렌더가 한 번 더 돌고 서버 스냅샷을 줄 자리가 없다 — `npm run lint` 가 `react-hooks/set-state-in-effect` 로 막는다.

**한 번 닫으면 다시 안 뜬다**(`localStorage`). `DESIGN.md` §8.1-4 가 강요하지 말라고 했다.

**`<head>` 에 실제로 박혔나** — 프리렌더된 HTML 을 직접 읽었다.

```
<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover"/>
<meta name="theme-color" content="#fff"/>
<link rel="manifest" href="/manifest.webmanifest"/>
<meta name="mobile-web-app-capable" content="yes"/>
<meta name="apple-mobile-web-app-capable" content="yes"/>
<meta name="apple-mobile-web-app-title" content="라스트마일"/>
<meta name="apple-mobile-web-app-status-bar-style" content="default"/>
<link rel="icon" href="/icon.svg?…" sizes="any" type="image/svg+xml"/>
<link rel="apple-touch-icon" href="/apple-icon.png?…" sizes="180x180" type="image/png"/>
```

`rel="manifest"` 가 **한 번만** 있다 — `metadata.manifest` 를 안 적었고 Next 가 `app/manifest.ts` 를 보고 알아서 넣는다. 둘 다 하면 두 번 박힌다.

**눈으로 봤다**(`DESIGN.md` §9 — 코드만 읽고 판단하지 않는다). 375×780 과 1280×860 에서 캡처했고 확인한 것 여섯.

**계산값을 직접 읽었다** — 눈으로만 보면 못 잡는 것들이다.

| 무엇 | 잰 값 | 뜻 |
|---|---|---|
| `nav[aria-label="주요 메뉴"]` 개수 / 노출 | **2 / 1** | 하나만 접근성 트리에 있다 |
| `.tabs` `padding-bottom` | **8px** | 포커스 링(5px)이 그려질 자리 |
| 탭 항목 아래 여백 | **8px** | 링이 뷰포트 아래로 안 잘린다 |
| 첫 탭 `x` | **8** (전 0) | 링이 옆으로도 안 잘린다 |
| `.main` `padding-bottom` | **128px** = `--s8` 64 + `--tabbar-h` 56 + `--tabbar-pad` 8 | 변수 셋이 맞물린다 |

**키보드로 실제로 탭 바까지 갔다**(Tab 반복). `:focus-visible` 은 프로그램 `focus()` 로는 안 뜬다 — 처음에 그걸로 찍어서 링이 없는 캡처를 한 번 만들었다. 링 네 변이 다 보이는 것을 확인했다(`phone-tab-focus.png`).

**백엔드를 띄우고 다시 찍었다.** 앞 라운드는 API 가 없어서 제품 목록이 오류 카드였다. `uvicorn finnect.api.app:app --port 8100` 을 올리니 공고 1,752건이 뜨고 그 위에 탭 바가 얹힌다(`phone-list.png`).

### 리뷰가 찾았지만 안 고친 것

**`/admin` 이 375px 에서 내비가 겹친다** — `첨부 해독` 과 `제품으로` 가 서로 위에 올라탄다(`phone-admin.png`).

**이 작업 전부터 있던 것이다.** `admin/layout.module.css` 에 `@media` 가 **0개**이고, 내가 거기 넣은 것은 안전영역 다섯 줄뿐이다. T-0023 이 "안 한 것: 내비게이션 구조 변경"이라고 그은 선이고, 폭이 넓은 이유도 적혀 있다 — 실행 기록이 11열이라 900px 에서 못 읽는다.

**다만 이 작업이 그 화면을 폰에서 닿게 만들었다.** `scope` 가 `/` 라서 설치본 안에서 열리고 제품 헤더에 링크가 있다. 고치려면 표 열 열한 개를 폰에서 어떻게 보여 줄지 정해야 하고 그건 `SPEC.md` §6(운영 도구 = 범위 밖)에서 다시 얘기할 일이다. **안전영역만 물리고 겹침은 남겨 뒀다.**

### 못 잰 것

**실제 기기에서 설치해 보지 않았다.** 헤드리스 크로미움은 `beforeinstallprompt` 를 안 쏘고 iOS 사파리도 없다. 설치 막대 둘은 **이벤트를 우리가 쏘고 `navigator.standalone` 을 심어서** 본 것이다 — 화면은 맞지만 `prompt()` 가 실제로 설치 창을 여는지는 안 봤다.

**Lighthouse installability 를 안 돌렸다.** 이 서버에 크롬 정식 채널이 없다(플레이라이트 번들 크로미움만 있다).

**안전영역이 실제로 얼마나 들어오는지 안 봤다.** 노치 있는 기기가 없다. `env()` 값이 열리는 것은 `viewport-fit=cover` 로 확인했지만, 그 값이 0 이 아닌 화면에서 본 적은 없다.

## 안 만든 것과 이유

**서비스 워커.** ADR-0039 결정 1. 오프라인은 낡은 데이터를 언제 버리는지부터 정해야 하고, 그 규칙은 사용자가 오프라인에서 무엇을 하려는지를 봐야 정해진다. **이 앱은 비행기 모드에서 안 돈다.**

**아이콘 세트.** 하단 탭 바에 글자만 있다. 아이콘을 넣으려면 아이콘 언어를 새로 정해야 하고 `DESIGN.md` 에 그게 없다.

**스플래시 이미지.** iOS 는 기기 해상도마다 다른 파일을 요구한다. 그 목록을 정확히 셀 근거가 없어서 `background_color` 로 뜨게 뒀다.

**`scope` 좁히기.** `/` 라서 운영 도구도 앱 안에서 열린다. 제품 라우트가 흩어져 있어 공통 접두사가 `/` 밖에 없다.

**푸시 알림.** `SPEC.md` §6 이 알림 발송을 범위 밖으로 뒀다.
