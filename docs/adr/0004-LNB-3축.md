# ADR-0004: LNB를 지원사업 / 신청 현황 / 사업계획서 3축으로

- 상태: 채택됨
- 날짜: 2026-08-15 (구 `PRD.md` D17 승계)

## 맥락

이 제품은 성격이 다른 세 가지를 다룬다. 아직 안 고른 공고, 진행 중인 신청 건, 쓰고 있는 문서다. 하나의 목록으로 합치면 "지금 뭘 해야 하는지"가 묻힌다.

## 결정

좌측 LNB를 세 축으로 나눈다. 각 축은 **다루는 단위가 다르다.**

| 메뉴 | 다루는 것 | 단위 | 클릭하면 |
|------|-----------|------|----------|
| 지원사업 | 지금 신청할 수 있는 공고 | 공고 | 공고 상세로 |
| 신청 현황 | 진행 중인 건의 마감과 상태 | 공고 | **다음 할 일로** |
| 사업계획서 | 지금까지 쓴 문서 | 문서 | 문서 편집으로 |

LNB 하단에 "진행 중 N · 마감 임박 N" 요약을 둔다. 신청 현황으로 들어갈 이유를 만든다.

## 결과

- **신청 현황의 존재 이유가 "다음 할 일" 열이다.** 이게 없으면 즐겨찾기와 다를 게 없다. 각 행에서 지금 해야 할 하나를 명시하고 버튼을 붙인다(F9-3).
- 상태를 자동으로 바꾸지 않는다. **제출은 우리 범위 밖이라 알 방법이 없고, 안다고 표시하면 거짓이 된다.** 사용자가 직접 바꾼다(F9-5).
- 같은 공고가 지원사업과 신청 현황 두 곳에 나타날 수 있다. 준비 시작을 누른 시점에 신청 현황으로 들어가고, 지원사업 목록에는 그대로 남는다.
