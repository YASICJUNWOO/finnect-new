# ADR-0053: 화면 번호를 SPEC 으로 통일한다

- 상태: 채택됨
- 날짜: 2026-08-22
- 관련: [ADR-0023](0023-제품-프론트를-nextjs로-분리한다.md) 제품 프론트 분리 · [ADR-0027](0027-운영-화면을-nextjs로-옮긴다.md) 운영 화면 · [plan/09](../plan/09-사용자-앱-분리.md) · [plan/21](../plan/21-동선을-끝까지-잇는다.md) T-0117

## 맥락

**두 문서가 다른 이름으로 같은 화면을 불러 왔다.**

| 화면 | `SPEC.md` §5.2 | CLAUDE.md · [plan/09](../plan/09-사용자-앱-분리.md) |
|---|---|---|
| 공고 목록 | **S2 추천**(F4) | S4 |
| 공고 상세 | **S3 공고 상세**(F5) | S5 |
| 신청서 쓰기 | **S4 문서**(F6) | 이름 없음 |
| 파일 올리기 | S1 온보딩(F1-1) | S1 |
| 내 사업 위키 | S7(F1-2~F1-7) | S7 |

어긋난 것은 가운데 셋이다. [plan/09](../plan/09-사용자-앱-분리.md)가 2026-08-17 사용자 앱을 열면서 목록·상세를 S4·S5 로 불렀고 CLAUDE.md 가 그것을 옮겨 적었다. **ADR 없이 계획 안에서 붙인 이름이다** — [plan/README](../plan/README.md)가 T-0019 에 대해 적어 둔 것과 같은 종류의 일이 한 번 더 일어났다.

이 어긋남이 실제로 무엇을 막았는지가 요점이다. [plan/16](../plan/16-항목마다-초안을-쓴다.md)과 [plan/17](../plan/17-맞는-공고를-고른다.md)이 **똑같은 문장으로 화면 슬라이스를 미뤘다**:

> **집필 화면.** `SPEC.md` §5.2 는 S4 를 문서(F6)로 두는데 [09](../plan/09-사용자-앱-분리.md)와 CLAUDE.md 는 S4·S5 를 공고 목록·상세로 부른다. **화면 번호가 문서끼리 어긋나 있어서** 슬라이스를 열 때 먼저 정한다

즉 **이름 하나가 두 계획의 화면을 동시에 세워 뒀다.** 백엔드가 다 서 있는데 화면을 못 연 이유 중 하나가 이것이다.

## 결정

**`SPEC.md` §5.2 가 이긴다.** CLAUDE.md 가 스스로 그렇게 적었다 — *「`docs/SPEC.md` — 정본. 무엇을 만드는가. 현재 진실이고, 충돌 시 이 문서가 이긴다」*. 새 규칙을 만드는 것이 아니라 이미 있는 규칙을 적용하는 것이다.

**1. 지금 S4·S5 라 부르는 둘은 S2·S3 이다.** 공고 목록이 **S2**, 공고 상세가 **S3** 이다.

**2. 신청서 쓰기가 S4 다.** `/notices/{source}/{id}/write` 와 `/documents/{표본}/write` 가 그 화면이고, 지금까지 이름이 없었다.

**3. 화면 수는 그대로 넷이다.** S1 · S2 · S3 · S7 이 서 있고 S4 가 [plan/21](../plan/21-동선을-끝까지-잇는다.md) 에서 선다. 없는 것은 S5 제출 가이드 · S6 신청 현황 둘이다.

**4. 번호를 코드 주석과 문서에 같이 고친다.** 파일 다섯과 문서 넷이다. **한 커밋에 넣는다** — 반만 고치면 지금보다 나쁘다.

**5. `SPEC.md` 를 고치지 않는다.** 정본이 맞았고 틀린 것은 옮겨 적은 쪽이다.

## 결과

- **[plan/16](../plan/16-항목마다-초안을-쓴다.md)·[plan/17](../plan/17-맞는-공고를-고른다.md)이 미뤄 둔 화면 슬라이스가 열린다.** 그 둘이 명시적으로 「먼저 정한다」고 한 것이 이 결정이다
- 새 화면(S4 초안)이 어느 번호로 설 지가 정해진다. **이름 없이 만들면 세 번째 어휘가 생긴다**
- `SPEC.md` §5.2 의 S2 가 「추천」이라 **목록 화면의 정체가 「추천이 위, 전체가 아래」인 두 섹션짜리라는 것이 이름에서 드러난다.** [plan/21](../plan/21-동선을-끝까지-잇는다.md) T-0119 가 그 위쪽을 채운다

### 포기한 것

**옛 이름으로 적힌 커밋 메시지와 evidence 문서를 고치지 않는다.** 기록이라 그대로 둔다 — 이 ADR 이 대응표다.

**「S4·S5」로 검색하던 습관이 한 번 깨진다.** 레포에서 그 두 낱말이 다른 화면을 가리키게 된다. 대가를 받는 대신 **정본과 코드가 같은 말을 쓴다.**

### 왜 반대로(SPEC 을 고쳐) 안 갔나

`SPEC.md` §5.2 의 번호는 F 기능 번호와 짝이 맞게 매겨져 있다 — S2↔F4 · S3↔F5 · S4↔F6. CLAUDE.md 쪽 번호는 그 짝이 깨진다(S4 가 F4 도 F6 도 아니다). **틀린 쪽을 정본으로 올리면 기능 번호와 화면 번호가 영영 안 만난다.**
