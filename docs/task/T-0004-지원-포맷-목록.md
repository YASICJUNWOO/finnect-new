# T-0004: 지원 포맷 목록 정의

- 상태: 대기
- 단계: [plan/02](../plan/02-수집과-추출.md)
- 선행: [T-0003](T-0003-스택-확정.md)

## 무엇을

F0-2가 다루는 첨부 포맷 목록을 **설정으로 관리**하고, 미지원·실패를 조용히 넘기지 않게 만든다.

## 왜

**실측 중 실제로 당했다.** DOCX 파서가 없어 초기창업패키지 첨부 20개 중 4개를 못 읽었고, 그 상태로 "배점이 없다"는 결론을 냈다. 파서를 붙여 다시 보니 결론은 같았지만 **바뀔 수도 있었다.**

창업진흥원은 사업계획서 양식을 HWP와 DOCX 두 벌로 붙인다. 포맷 하나가 빠지면 그 공고에 대한 판단이 통째로 틀릴 수 있다.

## 완료 조건

- 지원 포맷 목록이 코드가 아니라 설정에 있다
- **미지원 포맷을 만나면 기록에 남는다.** 조용히 건너뛰지 않는다
- 파싱 실패가 F0-6 신뢰도에 반영된다
- 공고 단위로 "첨부 N개 중 M개 해독"이 보인다

## 확인된 포맷과 방식

| 포맷 | 방식 | 추출률 |
|------|------|--------|
| HWP | OLE + raw deflate + 레코드 워크 | 100% |
| HWPX | ZIP + XML | 100% |
| DOCX | ZIP + XML | 100% |
| PDF | 텍스트 레이어 | 91% |
| ZIP | 미확인. 실측 표본에 27개 있었다 | — |
| XLSX | 미확인. 21개 | — |
