## 무엇을

백엔드 언어, DB, 프론트 프레임워크, LLM 제공자를 정하고 ADR로 남긴다.

## 왜

**어디에도 결정으로 기록된 적이 없다.** `.gitignore`가 Python(`__pycache__`, `.ruff_cache`, `.mypy_cache`, `.pytest_cache`)과 Node(`node_modules`, `.next`)를 전제하지만, 그건 관성이지 결정이 아니다.

스택은 나중에 바꾸면 전부 뜯어야 하는 것이라 [plan/01](../plan/01-기반.md)에서 먼저 정한다.

## 정할 것

| 항목 | 고려사항 |
|------|----------|
| 백엔드 언어 | HWP·HWPX·DOCX·PDF 파싱 라이브러리 가용성. 스파이크는 Python으로 전부 확인했다 |

| LLM | L1 추출(strict schema)과 L3 집필(스트리밍) 둘 다 필요 |
