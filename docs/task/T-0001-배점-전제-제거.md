# T-0001: 배점 전제 제거

- 상태: **막힘** — [ADR-0010](../adr/0010-배점-전제-폐기.md) 대체 설계 미결
- 단계: [plan/00](../plan/00-미결-해소.md)
- 선행: —

## 무엇을

배점 순 정렬을 전제한 설계를 걷어내고 확정 설계로 바꾼다. 지금은 잠정 문구가 들어가 있다.

## 왜

실측 결과 초기창업패키지·창업도약패키지가 배점을 공개하지 않고, 창업 분야 전체로도 명시율이 25%다. 30/30/25/15는 출처 불명 값이다.

**대체 설계가 정해지기 전에는 잠정 문구를 확정으로 바꿀 수 없다.** ADR-0010의 세 안 중 하나를 골라야 한다.

## 완료 조건

- ADR-0010 상태가 `채택됨`으로 바뀐다
- 아래 잠정 표기(⚠️)가 전부 사라진다
- 예시 데이터에서 배점 숫자가 사라진다 (이미 반영됨)
