## 읽을 때 주의할 것 넷

**1. `04_구현현황.md`는 이 레포 이야기가 아니다.** 기획이 만든 시연용 HTML(`demo_dark.html`, `redesign.html`)을 읽고 적은 문서다. 이 레포의 Python 코드와는 별개다. 이 레포가 실제로 무엇을 하는지는 [`../../../plan/README.md`](../../../plan/README.md)에 있다.

**2. 문서들이 참조하는 `../internal/`은 이 레포에 없다.** 회의록 원본이고 넘겨받지 않았다.

**3. 문서끼리 서로 안 맞는 곳이 있다.** SPEC.md §9에 미결로 올려 뒀다. 가장 큰 것은 **질문을 언제 하는가**다 — `설계정리` [5]·[8]은 온보딩에서 몰아 묻고 작성 중엔 안 묻는다(무인)고 하고, `02` F6-8과 `04` 시연 동선은 작성 중에 묻는다고 한다.

**4. 이 레포의 실측과 부딪히는 곳이 있다.** SPEC.md §8과 §9에 적었다. 배점과 마감일 두 건이 스키마를 바꾼다.
