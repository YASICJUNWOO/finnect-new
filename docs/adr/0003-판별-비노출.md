# ADR-0003: 자격 판별을 화면에 노출하지 않는다

- 상태: 채택됨
- 날짜: 2026-08-15 (기획서 v3 → v4)

## 맥락

v3까지는 **판정 근거를 사용자에게 보여주는 것**이 신뢰를 만든다고 봤다. 공고 상세에 요건별 4열 대조표를 두고, 충족·미충족·확인 불가 3분류를 표시하고, 확인 불가 항목은 표 안에서 바로 입력받아 재판정하는 설계였다.

문제는 그 설계가 **우리 일을 사용자에게 떠넘긴다**는 것이다.

사용자는 우리 판정을 검산하러 온 것이 아니다. 되는 공고를 알고 계획서를 쓰러 왔다. 검산 도구를 화면에 놓으면 수백 건을 직접 판별하던 기존 서비스의 문제를 형태만 바꿔 재현하게 된다.

## 결정

**판정은 뒤에서 정확하게 하고 화면은 결과만 준다.**

- F2 자격 판별에 **화면을 두지 않는다.** 프로필이 바뀌거나 색인이 갱신될 때 엔진이 전체 공고를 판정하고, 그 결과가 S1 목록이 된다.
- 목록에 오른 것 자체가 판정 결과다. 신청 가능한 공고만 올린다.
- 충족·미충족·확인 불가 3분류를 화면에서 없앤다.
- 중복 수령 제한은 별도 기능이 아니라 **F2-1 안에서 요건의 한 종류로** 다룬다. 화면 경고를 두지 않는다.
- 판별 조건 칩과 요건 대조 표를 삭제한다.
- 조건이 궁금하면 S8 내 정보에서 본다.

## 결과

- 화면이 단순해지고 사용자가 판별에 쓰는 시간이 0이 된다.
- 대신 **판정 정확도의 부담이 전부 엔진으로 간다.** 틀린 판정은 사용자가 알아챌 방법이 없다. [ADR-0002](0002-3계층-분리.md)의 L2 결정론 보장이 그래서 필수다.
- **목록만 보면 기존 추천 서비스와 구분이 안 된다.** 화면으로 차별점을 보여줄 수 없다는 뜻이다. 이 부분은 화면으로 보완하지 않기로 했다. 판별 정확도는 지표로 따로 제시한다.
- 중복 수령 제한을 판정에서 빼면 못 받는 공고를 받을 수 있다고 알려주게 되므로, 화면에서만 빼고 **판정 자체는 유지한다.**
