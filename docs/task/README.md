## 지금 할 수 있는 것

**T-0006과 T-0008이 T-0001을 푼다.** 둘 다 조사이고 코드가 거의 필요 없다. 이 둘의 결과가 [ADR-0010](../adr/0010-배점-전제-폐기.md)의 대체 설계 선택을 바꿀 수 있다.

- T-0008에서 주관기관이 배점을 준다는 게 확인되면 → 1안(분기)이 현실적이 된다
- T-0006에서 양식 목차가 기계적으로 파싱된다면 → 2안(양식 축)이 든든해진다
- 둘 다 안 되면 → 3안(타깃 축소)을 진지하게 봐야 한다
