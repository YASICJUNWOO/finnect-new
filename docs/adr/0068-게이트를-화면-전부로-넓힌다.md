# ADR-0068: 입장 게이트를 화면 전부로 넓힌다 — 「안 막아도 되는 화면」이 없었다

- 상태: 채택됨
- 날짜: 2026-08-24
- 대체하는 것: [ADR-0066](0066-베타-테스터를-이름과-비밀번호로-가른다.md) **결정 5 만.** 나머지(가입·로그인을 안 나눈다 · 평문 · opaque `company_id` · 쿠키가 세션이 아니다 · `?company=` 가 이긴다)는 그대로다
- 근거: [ADR-0066](0066-베타-테스터를-이름과-비밀번호로-가른다.md)

## 맥락

ADR-0066 결정 5 는 게이트를 화면 다섯에만 걸었다. 근거는 이랬다.

> 공고 목록(`/`)과 상세는 회사 없이도 도는 화면이라(추천 표시만 못 함) 그대로 열어 둔다 — **처음 링크를 받은 사람이 로그인부터 강요당하지 않는다.**

**괄호 안이 틀렸다.** 그 두 화면은 회사 없이 도는 것이 아니라 **회사가 없으면 `DEFAULT_COMPANY`(`c_dasiro`)로 떨어진다.** 같은 커밋에서 그 둘을 `currentCompany()` 로 바꾸면서 폴백을 그대로 둔 것이 이유고, 커밋 메시지에도 그렇게 적혀 있다 — 「쿠키가 없으면 예전처럼 `DEFAULT_COMPANY` 로 내려가서 기존 동작은 그대로다」.

그래서 실제로 일어나는 일은 이것이다. **입장하지 않은 사람이 `/` 를 열면 `c_dasiro` 의 추천 세 건을 자기 추천으로 본다.** 배포본에서 그 상태로 돌고 있었다(`GET /` → 200).

이것은 ADR-0066 이 막으려던 바로 그 실패다 — 「그 실패가 오류가 아니라 그럴듯한 화면으로 나타난다」. 결정 5 가 그 문장을 자기 화면 둘에 대해서만 면제해 준 셈이다.

**「로그인부터 강요당하지 않는다」의 값도 다시 봐야 한다.** 지금 이 제품은 **베타 테스터에게 링크를 주는 것**이 유일한 배포 경로다. 지나가던 사람이 공고를 구경하는 동선이 없다. 값이 없는 이득이었다.

## 결정

**게이트를 화면 전부에 건다.** `web/proxy.ts` 의 matcher 가 경로 목록이 아니라 **제외 목록**이 된다.

```js
matcher: [
  "/api/admin/:path*",
  "/((?!api/|_next/|enter|rhwp/|icon|apple-icon|manifest|favicon).*)",
]
```

빼는 것 넷이고 이유가 전부 다르다.

| 뺀 것 | 왜 |
|---|---|
| `enter` | **게이트 자신이다.** 넣으면 자기 자신으로 무한히 돈다 |
| `api/` | 제품 API. 걸면 **올리기가 리다이렉트를 받아 HTML 을 JSON 으로 읽고 죽는다** |
| `_next/` · 그림 · `manifest` · `rhwp/` | 정적 파일. 걸면 로그인 전에 CSS 와 아이콘이 안 나온다 |
| — | `api/admin/` 은 위에서 `api/` 로 빠지므로 **따로 다시 넣는다**(ADR-0067) |

**목록이 아니라 제외로 뒤집은 것이 요점이다.** 목록이면 **새 화면이 생긴 날 하나가 빠지고, 빠진 그 화면이 조용히 `c_dasiro` 를 쓴다.** 제외면 새 화면은 기본으로 막힌다 — 틀리는 방향이 안전한 쪽이다. `_ADMIN_PREFIX` 를 접두사로 판단한 것과 같은 판단이다(ADR-0067 결정 3).

**`DEFAULT_COMPANY` 를 안 지운다.** 여전히 `?company=` 데모 링크와 `FINNECT_COMPANY` 가 쓰고, 게이트를 지나온 요청은 항상 쿠키나 `?company=` 를 들고 있어서 폴백에 닿지 않는다. **지우면 로컬에서 CLI 로 세운 위키를 주소로 못 본다.**

## 결과

- **입장 없이는 아무 화면도 안 보인다.** 첫 방문이 `/enter` 다.
- **`?company=` 는 여전히 이긴다**(ADR-0066 결정 6). 데모 링크가 그대로 산다 — 그리고 그것이 게이트를 우회하는 유일한 길이라, **주소를 아는 사람은 여전히 남의 위키를 열 수 있다.** ADR-0066 결정 4 가 적은 그대로다: 막는 것은 사고이지 공격이 아니다.
- **`ADR-0066` 이 적어 둔 「처음 링크를 받은 사람이 로그인부터 강요당하지 않는다」가 없어졌다.** 공개 배포로 방향이 바뀌면 그때 다시 연다 — 그때는 폴백이 `c_dasiro` 가 아니라 **회사 없는 화면**이어야 하고, 그건 화면마다 「회사가 없을 때 무엇을 보여 주나」를 정하는 일이다. 이 커밋은 그것을 안 한다.
