## 1. 위키가 커졌다

```
              스텁      진짜
사실            65       187
  슬롯          34        39
  노드          30       143      ← 4.8배
근거 연결      118       214
읽은 파일      7/8       7/7
```

**자격 슬롯 여덟 값이 스텁과 같다.** 사람이 옮긴 것과 모델이 뽑은 것이 소재지·업종·
개업일·생년월일·직원 수까지 글자 단위로 일치했다. `--score` 가 "정형 슬롯은 거의
풀렸다(미스 6건)" 고 적은 것과 같은 결과다.

```
location       경기도 성남시 분당구 판교로 255, 3층 (삼평동)   as_of 2026-01-31
industry       정보통신업                                      as_of 2026-01-31
industry_item  응용 소프트웨어 개발 및 공급업                  as_of 2026-01-31

founded_on     2024-03-11        ceo_birth  1992-07-04
                                 → 업력 2.44년 · 만 34세
```

**같은 회사를 두 번 세우면 사실 수가 다르다.** 첫 번째 166건, 두 번째 187건이었다.
슬롯 값은 안 흔들렸고 흔들린 것은 서술 노드의 분해 단위다 — `--score` 의 "남은 미스
33건 중 27건이 서술 문장 쪼개기" 와 같은 축이다.

## 2. **위키가 공고를 삼켰다** — 스텁이 가리고 있던 결함

갈아 넣은 직후 추천 3건 중 **2건이 자기 자신이었다.**

```
[맞다] 2026년 민관협력 오픈이노베이션 지원 성과기업 후속 지원 창업기업 모집 수정 공고
       창업기업·사업화·기술개발이 주제예요. 창업기업 대상 공공기관과 협업 추진에
       필요한 사업화 자금은 과제별 최대 1억원이며 후속 연계 지원이 제공됨
                                        ↑ 이건 우리 사실이 아니라 그 공고의 문장이다
```

근거를 되짚으니 전부 한 파일에서 나왔다.

```
「민관협력_오픈이노베이션_지원」_'공공데이터_활용_지원'…모집공고.hwpx   사실 15건
  [330] finance   창업기업 대상 공공기관과 협업 추진에 필요한 사업화 자금은 …
  [336] solution  공공기관별 2개 이내 과제 제출 가능
  [338] solution  오픈이노베이션 운영위원회(서면평가)를 통해 선정함
  [340] solution  사업 문의 총괄기관은 중소벤처기업부 신산업기술창업과이며 …
```

**정부 공고문이 회사 사실로 들어앉았다.** 그리고 M 이 DB 에서 같은 공고를 찾아
"맞다" 를 냈다. 키워드가 완벽히 겹치는 게 당연하다 — 같은 문서다.

### 스텁은 이걸 못 만났다

화이트리스트가 그 파일을 몰라서 `chunked` 로 되돌려놨다. **막은 게 아니라 못 읽은
것이다.** 진짜 추출기는 아무 파일이나 읽고 **"이 문서가 우리 회사 얘기인가" 를
묻지 않는다.**

제품이 "가진 파일을 통째로 던지면" 이라고 말하고 그 제품이 공고를 다루므로,
**사용자가 공고문을 같이 올리는 것은 예외가 아니라 예상되는 일이다.**

### 이번에 한 것 / 안 한 것

- **한 것**: 그 파일을 `c_dasiro` 에서 뺐다. plan/15 업로드 화면을 시험하려고 8/18
  13:19 에 올린 것으로, 픽스처 7건(09:50~09:51)과 3시간 반 떨어져 있고
  `tests/fixtures/wiki/` 에 없다. **원본 바이트는 안 지웠다**
- **안 한 것**: 문서 종류를 가리는 관문. 뿌리는 추출 쪽이고 설계가 따로 필요하다

```
진짜 143노드   겹친 공고 26/209  (12%)
```

겹치는 낱말도 거의 그대로다.


→ **임베딩을 붙일지 정할 때 이 숫자를 쓴다.** "노드가 적어서" 라는 설명은 죽었다.

## 4. 추천을 세운 것은 ⑤가 아니라 ④였다 (T-0076)

층0 542건 · 정규화 209건 · 2026-08-21 기준.

```
후보 526
 ③ 자격    탈락 67 · 확인 필요 19 · 정규화 없음 432
 ④ 분야    맞음 5
 ⑤ 적합도  맞다 0 · 애매 5 · 아니다 3
```

**`맞다` 가 0 이다.** ⑤ 교집합이 자격을 넘은 8건에서 0/8 이었다. ④가 살린 5건에
`sectors.Match.cues` 로 이유를 붙였고 **그래서 추천이 섰다.**

```
[애매] 2026년 2차 기술개발제품 공공기관 실증지원 사업 공고
       기술 개발 분야예요. 1단계 모듈 프로토타입 개발을 완료했으며, 파일럿 매장 12곳을 운영 중이다.
[애매] [경기] 성남시 2026년 기술자료 임치 수수료 지원사업 신청 공고
       기술 개발 분야예요. 1단계 모듈 프로토타입 개발을 완료했으며, 파일럿 매장 12곳을 운영 중이다.
[애매] 2026년 민관협력 오픈이노베이션 지원 성과기업 후속 지원 창업기업 모집 수정 공고
       사업화 분야예요. 2027년 1월부터 6월까지 다점포 통합 관리를 출시하고 프랜차이즈 본부 대상 영업에 착수한다.
```

### 육안 8/8

| 등급 | 공고 | 눈으로 |
|---|---|---|
| 애매 | 민관협력 오픈이노베이션 (Bottom-Up) | 맞다 |
| 애매 | BOUNCE 2026 스타트업 오픈이노베이션 페스타 | 맞다 |
| 애매 | 민관협력 오픈이노베이션 성과기업 후속 지원 | 맞다 |
| 애매 | 기술개발제품 공공기관 실증지원 | 맞다 — 특허·프로토타입이 실재한다 |
| 애매 | [경기] 성남시 기술자료 임치 수수료 | 맞다 — 성남 + 기술. 가장 잘 맞는다 |
| 아니다 | 기술유출방지시스템 구축 (시설/입지) | 맞다 |
| 아니다 | [경기] 성남시 산업기술보호 컨설팅 | 맞다 |
| 아니다 | [경기] 성남시 하반기 해외전시회 | 맞다 — **④가 하려던 일이 정확히 이것이다** |

### CLI 와 API 가 갈렸다

`match/service.py` 의 `rep.top` 만 고치고 `api/service.py` 를 뒀더니 **CLI 는 셋을
찍는데 화면이 비었다.** 저쪽이 `verdict == MATCH` 로 걸러 두고 있었다.

**화면에 닿는 것은 API 쪽이다.** CLI 출력만 보고 "됐다" 고 했으면 못 잡았다 —
`curl` 로 열어 보고 잡았다.

### 등급을 안 올렸다

다섯 다 `애매` 그대로다. **분야가 맞는 것과 취지가 맞는 것은 다른 주장**이라
같은 등급에 넣으면 순서가 뜻을 잃는다([ADR-0013](../0013-판정-두-층.md)).
바꾼 것은 추천 필터다 — **등급이 아니라 이유로 거른다.**

### 이유가 같은 카드가 겹친다

`애매` 5건 중 3건이 같은 문장이다. ④가 버킷 열 개짜리라 같은 버킷이면 같은 노드가
걸린다. **거짓은 아니다** — 그 셋이 맞는 이유가 실제로 같다. 다만 카드 셋이 같은
둘째 줄을 다는 것은 화면 문제다(`DESIGN.md` §8.1-3). 다양성을 위해 더 나쁜 노드를
고르지는 않았다 — 육안 40건에서 다시 볼 자리다.

## 5. 이유 문장이 표 부스러기를 물고 나왔다

첫 출력이 이랬다.

```
사업화 분야예요. 통합 9만 9천원\t연동 + 다점포 통합 관리\t2027년 출시
```

탭을 막으니 이번엔 줄이 셋인 목록이 나왔다.

```
사업화 분야예요. 2027 상반기
다점포 통합 관리 출시
프랜차이즈 본부 영업 착수
```

**뿌리는 추출 쪽이다.** 스키마가 `text` 를 "사람이 읽는 문장" 이라고 적었는데 표
한 줄이 그대로 노드가 됐다 — `--score` 가 "깨진 3건은 전부 파서 노이즈" 라고 적은
것과 같은 부류다.

이유는 화면 카피라 `rank.quotable()` 로도 막았다. **일반 공백만 허용하고, 탭·줄바꿈이
있으면 인용하지 않는다.** 근거 링크로는 남긴다 — 사실이 아닌 게 아니라 인용이 안
되는 것뿐이다. **고쳐 쓰지 않는 이유는 `document_item` 과 같다** — 탭을 공백으로
바꾸면 원문에 없는 문장이 되어 근거 대조가 깨진다.
