# ADR-0001: 정본 문서 체계

- 상태: 채택됨
- 날짜: 2026-08-16

## 맥락

이전 `service_spec.md`의 첫 줄은 이렇게 선언하고 있었다.

> 정본 순서는 `context.md` → `PRD.md` → `function.md`다. 충돌 시 그 순서로 우선한다.

**그런데 `context.md`와 `PRD.md`가 존재하지 않았다.** `research.md`도 마찬가지다. 파일시스템과 Notion 어디에도 없다.

세 문서는 근거로 반복 인용되고 있었다. `research.md`만 9곳이다 — 디자인 방침(4.4), 토큰 방침(4.5), 정보 밀도(4.6), 심사 단계(2.3), 경쟁 조사(1장), 검사 체크리스트(5.3). 결론은 인용한 문서 안에 남아 있고 근거만 사라진 상태였다.

이 상태의 문제는 두 가지다.

1. 근거를 따라가면 막다른 길이라 **검증된 사실인지 그냥 적힌 것인지 구분이 안 된다.**
2. 정본 1·2순위가 없으므로 **충돌 시 무엇을 따를지 정할 수 없다.**

## 결정

**없는 문서를 복원하지 않는다.** 대신 체계를 다시 세운다.

| 역할 | 문서 |
|------|------|
| 제품 정본 | `SPEC.md` — 충돌 시 이것이 우선한다 |
| 화면 | `design/` |
| 결정과 근거 | `adr/` |
| 일정 | `plan/` (태스크 포함) |
| 폐기된 방향 | `archive/` |

`function.md`와 `service_spec.md`는 `SPEC.md`로 통합해 삭제했다. 내용은 git 이력에 남는다.

`context.md`·`PRD.md`·`research.md`를 복원하지 않는 이유는 **이미 내려진 결정을 되짚는 일이라 비용 대비 효과가 낮기 때문**이다. 결론은 이미 하위 문서에 반영돼 있다. 대신 사라진 근거에 의존하던 **사실 주장은 실측으로 다시 확인했다**([evidence](evidence/2026-08-16-첨부파싱-배점실측.md)).

## 결과

- 근거 없는 참조 8곳을 제거했다. 이제 문서 안의 모든 링크가 실존한다.
- 사실 주장 세 개(U1·U2·U3)를 실측으로 재확인했고, 그 결과 **하나가 반증됐다**([ADR-0010](0010-배점-전제-폐기.md)).
- **D3, D6~D10 여섯 개 결정은 영구히 유실됐다.** 이전 문서가 "화면을 규정하는 것만" 12개를 옮겨 적었고 원본이 없다. 필요해지면 새로 결정한다.
- 확인된 사실은 `SPEC.md` §8에 날짜와 함께 모았다. 앞으로 사실 주장은 근거 링크 없이 문서에 넣지 않는다.
