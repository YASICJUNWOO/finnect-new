## 승계하는 것

plan/08 "정해 둔 것"(26~36행)을 그대로 가져온다. **하나만 바뀐다.**

| 무엇 | 어떻게 |
|---|---|
| 사용자 화면 | ~~`src/finnect/web/`~~ → **`web/` (Next.js)**. admin과 아무것도 공유하지 않는다 |
| 목록 형태 | 시연의 **'전체 공고' 행 형태**. 카드 3열은 추천용이고 우리는 추천이 없다 |
| **데이터가 없는 자리** | **자리를 놓고 "아직 없어요"로 버틴다.** 레이아웃은 시연과 같게 두고 빈 화면 카피를 넣는다 |
| 예시 데이터 | **안 쓴다.** 근거 없는 값을 화면에 두지 않는다 |

**"아직 없어요"로 버티기로 한 것이 이 계획의 성격을 그대로 정한다.** 지금 채울 수 있는 것은 개요와 첨부뿐이다. 화면이 미완성으로 읽히는 것을 받아들인다 — 가짜 값으로 완성돼 보이는 것보다 낫다.

### 지금 채울 수 있는 것

| 시연의 자리 | 우리 데이터 |
|---|---|
| 마감 D-day | `apply_end`. **날짜가 아니면 원문을 그대로 쓴다** |
| 제목 · 기관 · 분야 | `notice` 뷰 |
| 개요 | `summary`. **HTML 엔티티가 섞여 온다** — 풀어야 한다 |
| 낼 서류 | `attachment`. **해독 상태까지 붙는다**(07) |
| 원문 보기 | `detail_url` |

### "아직 없어요"로 둘 자리

추천 공고 3건(F3-2 없음) · 왜 맞는지(F1 없음) · 자격(프로필 없음) · 어떻게 심사해요(F2-3 안 함) · 놓치기 쉬운 것 · 지원 형태와 금액(**두 API 모두 안 준다**) · ★ 저장과 칸반 · 초안 있어요(F6 없음).

### T-0024 공고 JSON API

- 상태: **완료** (2026-08-17) — `src/finnect/api/`. 계약은 [`api-contract.md`](../api-contract.md)
- 선행: —
- 푸는 것: [plan/01](01-기반.md)이 미뤄 둔 `api-contract.md`

`src/finnect/api/`. **admin과 별개 앱이다.**

**왜 별개인가.** admin은 `SPEC.md` §6 범위 밖이고 제품 API는 범위 안이다. 한 앱에 섞으면 그 경계가 코드에서 사라진다. [ADR-0020](../adr/0020-스택-확정.md)이 관리 화면을 Jinja2로 둔 이유가 "제품 프론트와 섞지 않는다"였다.

**완료 조건**

- `uv run uvicorn finnect.api.app:app --port 8100` 으로 뜬다
- `GET /api/notices` — 검색·출처 필터·정렬·페이징. **마감된 공고가 기본으로 안 나온다**
- `GET /api/notices/{source}/{external_id}` — 상세. **첨부와 해독 상태가 함께 나온다**
- 응답이 `views.py`의 `Notice` 필드명을 그대로 쓴다. **API 필드명을 새로 짓지 않는다**
- 접수 기간이 날짜가 아닌 것을 **원문 필드로 함께 낸다.** 프론트가 판단하지 않는다
- 없는 공고에 404. 모르는 출처에 404
- 계약 문서를 남긴다

**건드리는 것** — `src/finnect/api/`, `docs/api-contract.md`, `README.md`

### 딸려 나온 것

**`app/loading.tsx`를 루트에 두면 404가 200이 된다.** 루트 Suspense가 셸을 먼저 흘려보내 `notFound()`가 상태 코드를 못 세운다. `app/(list)/`로 옮겨 목록에만 걸리게 하니 404가 맞아졌다. **상세에는 로딩 스켈레톤이 없고**, 그게 이 교환의 대가다 — 단일 행 조회라 감수할 만하다.
