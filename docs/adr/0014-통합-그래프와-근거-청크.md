# ADR-0014: 통합 그래프 하나를 쓰고 모든 값에 근거 청크를 매단다

- 상태: 채택됨
- 날짜: 2026-08-16
- 대체: [ADR-0006](0006-사실고정-화면-미표시.md)
- 근거: [`설계정리_개발논의용.md`](evidence/2026-08-16-v2-기획문서/설계정리_개발논의용.md) §2 §3, [`03_데이터모델.md`](evidence/2026-08-16-v2-기획문서/03_데이터모델.md) §11

## 맥락

위키 시각화, 공고 매칭, 문서 집필 셋이 각자 다른 소스를 쓰면 동기화 비용과 불일치가 생긴다.

그리고 출처 문제가 있었다. 초기 설계는 노드 머리말에 `출처: IR_2026Q2.pdf 8쪽`이라는 **문자열**을 두었다. 사람이 읽을 수는 있지만 원문으로 되짚을 수 없다. 원본 파일을 그래프의 노드로 두는 방식도 함께 썼는데, 파일 하나가 노드 서넛으로 뻗어 선을 가장 많이 만들었다.

집필에도 걸린다. `Node.value`는 손실 압축이라 서술과 수치가 날아간다. 값만 들고 문단을 쓰면 모델이 나머지를 지어낸다.

## 결정

**통합 그래프 하나가 허브다. 그리고 모든 값이 자기 근거 청크를 직접 들고 있다.**

```
Document (올린 파일 원본)
  └─ Chunk (전처리된 원문 조각 + 위치정보: 파일 · 쪽 · 표 좌표)

Node (구조화 항목)
  ├─ value        구조화된 값        → 시각화와 매칭이 쓴다
  ├─ evidence ──▶ 자기 근거 Chunk[]  → 집필이 쓴다
  ├─ source_type  document | user_stated
  └─ ...

Edge (노드 간 관계)
```

1. **원본 파일은 노드가 아니다.** `Document` 계층으로 따로 둔다. 노드 21 → 15, 연결 37 → 21로 **43% 준다.** 껐다 켜는 상태를 관리할 필요도 사라진다.
2. **출처는 문자열이 아니라 연결이다.** 노드에서 원문 조각을 그 자리에서 연다.
3. **집필은 해당 노드에 매달린 청크만 꺼내 쓴다.** per-user 격리가 필수다.
4. **근거 없는 값은 지어내지 않고 `[확인 필요]`로 본문에 박는다.**
5. **문단별로 근거를 표시할 수 있다.**
6. **진짜 그래프DB를 쓰지 않는다.** 관계형·문서 저장 + "노드로 청크를 필터링해 꺼내는" GraphRAG 로직만 채택한다. 다중 홉 추론이 필요해지면 그때 다시 정한다.

**5번이 [ADR-0006](0006-사실고정-화면-미표시.md)을 뒤집는다.** 그때는 사실 고정을 화면에 표시하지 않기로 했다. 근거는 셋이었다 — 판별 근거를 걷어낸 것과 같은 성격이다, 읽는 흐름을 방해한다, 내보낼 때 지워야 할 요소가 는다.

첫 번째 근거가 이제 성립하지 않는다. **[ADR-0013](0013-판정-두-층.md)이 적합도 근거를 화면의 중심(F5-1)으로 올렸다.** 근거를 보여주는 것이 이 제품의 신뢰 장치가 됐으므로, 문단별 근거만 감추는 쪽이 오히려 일관되지 않는다. 나머지 두 근거는 표시를 기본값이 아니라 **펼쳐 보는 것**으로 두어 해소한다.

## 결과

- **출처를 나중에 붙이는 것은 불가능하다.** 청크에 위치정보를 심는 것은 파싱 단계에서만 할 수 있다. F1-1-3이 위치정보를 보존해야 하는 이유다.
- **파싱이 제품 전체의 병목이 된다.** 위치정보를 품은 청크가 안 나오면 근거도 집필도 없다. HWP 파서·OCR·표 구조 보존이 여기 걸린다.
- 노드 상세의 출처 한 줄이 **근거 청크 목록**으로 바뀐다. 그래프에서 원본 파일 켜고 끄기 버튼이 사라진다. 켤 노드가 없다.
- **`Ingest`(파일 → 만든 노드) 관계는 남는다.** 화면의 원본 파일 탭이 이걸 보여준다. 다만 그래프에는 안 그린다.
- **저장 비용이 는다.** 원본 파일, 청크, 노드 값이 각각 남는다. 보관·삭제 정책이 필요하다.
- 미결: 노드의 `상태`·`flag`(끊김·모순)와 설계안의 `status`·`confidence`를 어떻게 합칠지. 끊김과 모순은 그래프 위상과 병합 결과에서 나오는 것이라 신뢰도 점수로 표현되지 않는다. `SPEC.md` §9.
