## 왜 이게 공고문 사례보다 나쁜가

T-0077 은 **공고문**이 삼켜지는 것으로 처음 잡혔다. 공고문은 사업 얘기처럼 읽히니
추출기가 헷갈릴 여지가 있었고, 증상도 「M 이 자기 자신을 추천한다」로 나타났다.

이 파일은 **사업 얘기로 읽힐 구석이 하나도 없다.** 그런데도 24건이 섰다. 즉 추출기가
헷갈린 것이 아니라 **애초에 「이 문서가 우리 회사 얘기인가」를 묻지 않는다.**

`topics.py` 가 라우팅을 표로 둔 이유와 같은 자리다. 문서 종류 판별도 **모델의 재량에
남기면 안 된다**는 뜻으로 읽힌다.
