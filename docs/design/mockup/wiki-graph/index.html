사업 위키 · 자리 열다섯을 무엇으로 그릴 것인가

궤도 구조는 넷 다 같다. 중심 하나 · 안쪽 다섯 · 바깥 아홉, 각도가 구획을 뜻하고 자리는 고정이다(ADR-0017). 색이 말하는 것도 그대로 종류 하나다. 갈리는 것은 자리를 무엇으로 그리는가 하나 — 납작한 원이냐, 행성이냐, 유리 구슬이냐, 젤리냐. 데이터도 같다: 자리 15개, 채운 것 10개, 값이 갈린 것 1개.

구체를 그리려면 색이 셋 필요하다. 밝은 면 · 본색 · 그늘. 지금 토큰에는 종류마다 한 색뿐이라 (--n-identity 등) 나머지 둘을 시안이 임의로 만들었다. 전부 같은 색조에서 뽑았으므로 말하는 것은 여전히 종류 하나지만, 고르면 DESIGN.md §4.1 에 색 셋을 정식으로 올려야 한다. base.html(현행)만 제품 토큰을 그대로 링크한다.

재서 알게 된 것

  • 구체로 그리면 44px 타깃 문제가 같이 풀린다. 현행 도트는 지름 30px(측정 44px, 이름표 포함)인데 구체 셋은 78 · 64 · 66px 이다. 음영이 보이려면 그 크기가 필요했고, 결과적으로 DESIGN.md §8.2 를 넘긴다. 궤도 반지름을 158/286 으로 넓힌 것이 그 대가다.
  • 세로가 60px 늘어난다. 넷 다 1199px 로 같다 — 껍데기가 같고 그래프 판만 640→700 으로 커졌다.
  • 이름표 겹침은 넷 다 0이다. 구체를 키워도 이름표는 안 부딪힌다.
  • 빈 자리 이름표가 셋 다 처음에 AA 미달이었다. 현행도 마찬가지다(--ink-3 2.65:1). 셋은 고쳤고 현행은 아직 미달이다 — 시안과 무관한 기존 문제다.
  • 남은 미달 다섯은 전부 구체 자체다. 글자가 아니라 UI 요소라 기준이 3:1 인데(WCAG 1.4.11) B 유리가 3.9 · C 젤리가 3.1 로 걸치고 있다. 단색 기준으로 잰 값이라 실제 구체는 그라데이션이다 — 고르면 가장 어두운 지점으로 다시 재야 한다.
  • C 젤리만 기본 애니메이션이 돈다. 5.5초 주기로 아주 얕게 흔들린다. prefers-reduced-motion 에서 멈춘다.

다시 재려면

npm i --no-save playwright@1.62.1 && npx playwright install chromium 한 번 하고, node assets/measure.mjs · node assets/contrast.mjs · node assets/shot.mjs.
