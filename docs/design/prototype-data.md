## 3. 초기창업패키지 상세 (실측값)

여기 값은 2026년도 초기창업패키지(일반형) 실제 공고문에서 확인한 것이다.

| 항목 | 값 |
|------|-----|
| 접수 기간 | 2026-01-23 ~ 2026-02-13 16:00 |
| 지원 규모 | 일반형 최대 1억원 |
| 협약 기간 | 10개월 |
| 신청 자격(업력) | 창업 후 3년 이내 |
| 접수 방법 | K-Startup 온라인 |
| 심사 단계 | 3단계 — 서류평가 → 심층인터뷰(30분 이내) → 발표평가 |
| 서류평가 선별 | 2배수 내외 |
| 커트라인 | 단계별 60점 미만 제외 |
| 가점 | 최대 3점 |
| 사업계획서 분량 | 15페이지 내외 (목차 제외) |
| 탈락 조건 | 지정 양식 미준수 시 평가대상 제외 / 마감 후 수정·삭제 불가 |

### 평가 항목

**배점은 공고가 공개하지 않는다.** 항목명과 평가 관점만 나온다.

| 항목 | 평가 관점 |
|------|-----------|
| 문제인식 | 창업 아이템의 개발 배경 및 필요성 등 |
| 실현가능성 | 사업기간 내 개발 또는 구체화 계획 등 |
| 성장전략 | 사업화를 위한 차별성, 수익모델, 자금조달 방안 등 |
| 팀(기업) 구성 | 대표자 및 고용 (예정)인력이 보유한 기술 역량과 노하우 등 |

### 사업계획서 목차 (별첨1 양식)

| 항목 | 세부항목 |
|------|----------|
| □ 일반현황 | 창업아이템명, 산출물, 대표자 및 팀원 |
| □ 개요(요약) | 창업아이템 소개, 4개 항목 요약 |
| 1. 문제 인식 (Problem) | 창업 아이템의 필요성 — 국내외 시장 현황·문제점, 개발 필요성 |
| 2. 실현 가능성 (Solution) | 개발 계획 — 제품·서비스 구체화 계획, 차별성·경쟁력 확보 전략, 사업비 집행 계획 |
| 3. 성장전략 (Scale-up) | 사업화 추진 전략 — 경쟁사 분석, 시장 진입 전략, 수익화 모델, 투자유치 전략, 로드맵 |
| 4. 팀 구성 (Team) | 대표자 및 팀원 구성 계획 — 대표자 보유 역량, 팀원 역량, 업무파트너 |
