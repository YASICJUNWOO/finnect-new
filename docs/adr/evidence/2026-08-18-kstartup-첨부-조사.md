## 3. 파서

```html
<div class="board_file">
  <li class="clear">
    <a class="file_bg" title="[첨부파일] 200401_서강비즈니스센터 모집공고(연장).hwp">…</a>
    <div class="btn_wrap"><ul>
      <li><a onclick="fnPdfView('0FOmn')" class="btn_view">바로보기</a></li>
      <li><a href="/afile/fileDownload/0FOmn" class="btn_down">다운로드</a></li>
    </ul></div>
  </li>
```

`file_bg` 의 `title` 과 뒤따르는 `fileDownload/ID` 를 짝지으면 된다. 표본 15건에서 **30/30 을 뽑았다.**

```python
PAIR = re.compile(
    r'<a[^>]*class="file_bg"[^>]*title="(?:\[첨부파일\]\s*)?([^"]+)"'
    r'.*?href="(/afile/fileDownload/[^"]+)"', re.S)
```

**링크 텍스트로 파일명을 잡으면 안 된다** — 전부 `다운로드` 다.

## 5. 포맷 분포 — 우리 파서에 유리하다

표본 30개 기준.

| 확장자 | 개수 | 우리 파서 |
|---|---:|---|
| hwp | **16 (53%)** | **100% 해독** |
| pdf | 9 (30%) | 86.1% |
| jpg · png | 3 (10%) | OCR ([ADR-0030](../0030-OCR은-rapidocr-로컬로-하고-검출은-server-를-쓴다.md)) |
| hwpx | 1 | 100% |
| pptx | 1 | 있다 (첨부 목록에는 없음) |

**절반 이상이 HWP** 다. 기업마당(hwp 1,506/3,354 = 45%)보다 비중이 높고, 그건 우리가 100% 읽는 포맷이다.

## 6. 함정 — 파일명을 응답 헤더에서 가져오면 깨진다

## 7. 이 조사가 못 말하는 것

- **표본이 15건이다.** 공고당 2.00개는 추정이고, 첨부가 몰린 공고가 있으면 총량이 크게 움직인다
- **총 용량을 모른다.** 파일 하나만 받아 봤다. 기업마당 평균(610KB)으로 잡으면 36GB, 표본값(191KB)으로 잡으면 11GB다 — **세 배 차이라 예산을 못 세운다**
- **일 한도를 모른다.** 상세 페이지는 API 가 아니라 웹이라 `X-RateLimit` 이 없다. 29,789회를 연속으로 때렸을 때 차단되는지 안 재 봤다
- **오류 페이지를 HTTP 200 으로 주는지 안 봤다.** 기업마당이 그랬다([CLAUDE.md](../../../CLAUDE.md) 함정). 안 거르면 오류 HTML 이 hwp 로 저장된다
- **`fnPdfView('0FOmn')` 로 뜨는 미리보기가 원본과 같은지 안 봤다.** 같다면 PDF 로 받는 길이 하나 더 있다
