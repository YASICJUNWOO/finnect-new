## v2 피봇에서 살아남은 결정 둘

전부 뒤집힌 것이 아니다. 이 둘은 v2에서도 그대로다.

**[0003 판별 비노출](0003-판별-비노출.md).** 자격 미달 공고는 여전히 화면에 올리지 않고 요건 대조표를 두지 않는다. [0013](0013-판정-두-층.md)이 노출하기로 한 것은 **적합도의 이유**이지 자격 판정 근거가 아니다. 새 층이 위에 생긴 것이지 이 결정이 뒤집힌 것이 아니다.

**[0005 실제 심사 항목명](0005-실제-심사-항목명.md).** "공고마다 항목명이 다르므로 고정 목록을 코드에 박을 수 없다"가 v2의 "PSST로 고정하지 않는다"와 같은 말이다. 실측이 나중에 이 판단을 강화했다 — 지자체는 자체 양식을 쓴다.

## 형식

```
# ADR-NNNN: 제목

- 상태: 채택됨 | 제안됨 | 미결 | 대체됨(→ NNNN)
- 날짜: YYYY-MM-DD

## 맥락      무엇이 문제였나
## 결정      무엇으로 정했나
## 결과      그래서 무엇이 달라지나. 포기한 것 포함
```

번호는 재사용하지 않는다. **뒤집힌 결정은 지우지 않고 본문도 고치지 않는다. `상태:` 줄만 바꾸고 새 번호를 만든다.**
