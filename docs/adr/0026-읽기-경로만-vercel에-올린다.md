# ADR-0026: 읽기 경로만 Vercel에 올리고 수집·해독은 로컬에 남긴다

- 상태: 채택됨 — **일부 대체됨**([ADR-0027](0027-운영-화면을-nextjs로-옮긴다.md), 2026-08-17). 운영 조회 화면은 올라간다. 수집·해독·첨부 원본·수집 실행 버튼은 이 문서대로 로컬에 남는다
- 날짜: 2026-08-17
- 채우는 것: [ADR-0023 "안 정한 것"](0023-제품-프론트를-nextjs로-분리한다.md#안-정한-것) — 배포 위치
- 건드리는 것: [ADR-0021](0021-인프라-선정을-미룬다.md)이 미뤄 둔 항목 중 **저장소(A) 하나만**

## 맥락

[ADR-0023](0023-제품-프론트를-nextjs로-분리한다.md)이 "프론트를 따로 배포할 수 있는 상태가 된다"고 해 두고 위치는 안 정했다. [plan/09](../plan/09-사용자-앱-분리.md)도 "로컬까지다"로 닫았다.

**시연 URL 이 필요해서 그 결정을 지금 한다.** plan/README 가 적었듯 마감이 있고 MVP 완성도가 30점으로 가장 크다([`SPEC.md`](../SPEC.md) §1.5).

### 이 저장소가 Vercel 에 안 맞는다고 적었던 것들

셋 다 사실이고 지금도 그렇다.

1. **첨부 원본 1.7GB 가 로컬 디스크에 산다**(`config.py` `attachment_dir`). 서버리스에 그 디스크가 없다.
2. **수집이 응답보다 오래 산다.** `ingest/jobs.py` 가 데몬 스레드를 띄우고 K-Startup 전량이 149회다. `attach` 는 30분짜리다.
3. **두 API 인증키가 IP 에 묶일 수 있다.** 기업마당 키는 신청한 IP 에서만 동작할 수 있다.

**셋 다 쓰기 경로의 것이다.** 읽기 경로 — 목록·상세 두 화면과 그걸 먹이는 API — 는 하나도 해당하지 않는다.

## 결정

**읽기 경로만 올린다.**

| 무엇 | 어디 | 왜 |
|---|---|---|
| 사용자 화면 `web/` | **Vercel** 프로젝트 `finnect-web`. 루트 `web/` | Next.js 다 |
| 제품 API `src/finnect/api/` | **Vercel Python Function** 프로젝트 `finnect-api`. 루트는 레포 루트 | 읽기 전용 2엔드포인트. 파일도 안 쓰고 오래 도는 것도 없다 — 서버리스 모양 그대로다 |
| PostgreSQL | **Neon** (Vercel Marketplace) | 74MB 라 무료 한도(0.5GB) 안이다. 스키마는 alembic 이 그대로 만든다 |
| 수집 CLI · 해독 CLI | **안 올린다.** 로컬에서 돈다 | 위 1·2·3 이 전부 여기 있다 |
| 운영 도구 `admin/` | **안 올린다.** 로컬에서 돈다 | `SPEC.md` §6 범위 밖이고 인증이 없다 |

**프로젝트를 둘로 가른다.** 한 프로젝트에 Next.js 와 Python 함수를 섞으면 루트 디렉터리가 하나뿐이라 `web/` 과 레포 루트를 동시에 가리킬 수 없다. [ADR-0023](0023-제품-프론트를-nextjs로-분리한다.md)이 이미 "별개 프로세스"로 갈라 둔 것이 배포에서도 그대로 간다.

**API 함수 의존성을 따로 적는다**(`requirements.txt`). `pyproject.toml` 보다 짧다 — 읽기 API 는 `httpx` 도 `pdfplumber` 도 `olefile` 도 안 쓴다. 실제로 `import finnect.api.app` 이 로드하는 서드파티는 넷뿐이다.

**Preview 로 올리고 Vercel Authentication 을 켠다.** 화면 대부분이 "아직 없어요"로 비어 있는 상태라 공개 제품이 아니다.

## 결과

- **배포된 DB 는 스냅숏이다.** 공고가 갱신돼도 저절로 안 따라간다. 로컬에서 수집하고 다시 부어야 한다 — 절차는 [`docs/deploy.md`](../deploy.md)에 있다. **이것이 이 결정의 가장 큰 대가다.**
- 실측 덤프는 **101MB, gzip 20.3MB, 2.7초**다. 여섯 표 전부이고 `raw_fetch` 가 들어가는 이유는 두 공고 표가 FK 로 걸려 있어서다.
- `src/finnect/api/service.py` 가 **`attach.service.per_notice` 를 안 쓰고 같은 질의를 직접 든다.** 그 모듈이 내려받기와 파서를 함께 끌고 오기 때문이다. 읽기 API 가 다운로더에 딸려 갈 이유가 없다.
- [ADR-0021](0021-인프라-선정을-미룬다.md)의 미결 여덟 중 **A(저장소 구성)의 절반만 닫힌다.** 관계형 저장은 Neon 으로 정했고 **벡터 저장은 여전히 미정이다.** 큐·워커(B)와 파서(C)는 이 문서가 안 건드린다.
- **포기한 것** — 배포본에서 수집을 돌리는 것이다. 시연 중에 새 공고를 받아 보일 수 없다. 그 대가를 받아들이는 이유는 수집을 서버리스에 올리는 비용이 지금 얻을 것보다 크기 때문이다. 필요해지면 워커를 정하는 작업(ADR-0021 B)에서 다시 본다.

## 안 정한 것

**Production 승격을 안 정한다.** Preview 까지다. 도메인도 안 붙인다.

**첨부 원본을 안 올린다.** 화면은 첨부 **메타와 해독 상태**만 보여 주고 파일 링크는 출처 원본을 가리킨다. 1.7GB 를 오브젝트 스토리지에 올리는 것은 위키(F1)가 사용자 파일을 받을 때 함께 정한다 — [ADR-0021](0021-인프라-선정을-미룬다.md)이 그렇게 미뤄 뒀다.

**서버리스 커넥션 정책을 안 정했다.** `db.py` 가 모듈 로드 때 엔진을 만들고 `pool_pre_ping=True` 를 쓴다. Neon 의 **pooled 연결 문자열**(`-pooler`)을 쓰는 것으로 시작하고, 동시 콜드 스타트에서 커넥션이 마르면 그때 `NullPool` 을 본다. **실측 없이 미리 바꾸지 않는다.**
