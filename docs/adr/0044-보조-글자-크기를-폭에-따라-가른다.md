# ADR-0044: 보조 글자 크기를 폭에 따라 가른다 — 넓으면 13px, 좁으면 16px

- 상태: 채택됨
- 날짜: 2026-08-21
- 여는 것: 공고 목록·상세 시안 비교 — [`docs/design/mockup/notice/`](../design/mockup/notice/README.md) `R 적응` 채택
- 관련: [ADR-0041](0041-토큰-실값을-remember-canonical-로-바꾼다.md) 토큰 실값 · [ADR-0047](0047-브레이크포인트를-1024와-640으로-못-박는다.md) 폭 경계

## 맥락

`DESIGN.md` §3 이 **「14px 과 15px 이 없는 것이 이 표의 요점이다. 본문은 16px 이상이다」** 라고 적었다. 그런데 `tokens.css` 는 `--t-caption: 12px` 과 `--t-small: 13px` 을 들고 있고, 공고 화면이 그 13px 을 마감·기관·출처·부제에 쓴다.

**현행 화면의 본문 최소가 13px 이다.** 시안 비교의 실측표에 그렇게 나왔고, 재는 규칙은 「제 텍스트가 25자 넘는 요소」 — 배지 안 숫자가 아니라 산문이다. 이것은 시안을 고르기 전에 이미 걸려 있던 위반이다.

고치는 길이 둘이었다.

1. **전부 16px 로 올린다.** `A 규범` 이 그렇게 했다. 그러면 §3 을 글자 그대로 지키지만 목록 폭이 672px 로 좁아지고 행 높이가 95px 이 된다 — 첫 화면에 6행이다.
2. **폭에 따라 가른다.** `R 적응` 이 그렇게 했다. 넓은 화면은 13px 을 유지해 39px 행과 12행을 얻고, 좁은 화면은 16px 로 올린다.

2를 골랐다. 이유는 **같은 13px 이 두 화면에서 다른 물건이기 때문이다.** 1440px 모니터에서 13px 은 눈에서 60cm 떨어진 조밀한 표의 보조 정보이고, 390px 폰에서 13px 은 손에 든 화면의 본문이다. §3 의 규칙이 겨눈 것은 후자다.

**대가가 분명하다. 위반이 폭에 따라 켜졌다 꺼진다.** 같은 제품이 1024px 위에서는 §3 을 어기고 아래에서는 지킨다. 이것을 없애려면 넓은 화면도 16px 로 올려야 하고, 그러면 이 시안을 고른 이유(밀도)가 사라진다.

## 결정

**1. 보조 글자용 토큰을 새로 만든다.** `--t-aux` · `--lh-aux`. 기본이 16px 이고 1024px 위에서 13px 이 된다.

```css
:root { --t-aux: 16px; --lh-aux: 1.45; }
@media (min-width: 1024px) { :root { --t-aux: 13px; --lh-aux: 1.5; } }
```

**2. `--t-small`(13px) 을 고치지 않는다.** 159곳이 그 이름을 읽고 있고 대부분이 운영 화면과 위키 화면이다. 그 값을 폭에 따라 흔들면 이 작업이 안 본 화면 열댓 장이 같이 흔들린다. `DESIGN.md` §5 가 운영 라우트를 별도 표면으로 못 박았고, 거기 밀도를 제품 화면 결정으로 바꾸지 않는다.

**3. `--t-aux` 를 쓰는 자리를 공고 화면과 껍데기로 한정한다.** S4 목록 · S5 상세 · 행 · 필터 줄 · 상단 막대다. 위키·문서·운영 화면은 이 작업의 범위 밖이고, 거기 13px 본문은 **아직 걸려 있는 채로 남는다.**

**4. §3 의 문장을 고친다.** 「본문은 16px 이상이다」에 폭 조건을 붙인다. 규칙을 지우는 것이 아니라 **어디에 걸리는지를 적는다** — 좁은 화면에서는 그대로 걸린다.

## 결과

- 좁은 화면(<1024px) 공고 화면의 본문 최소가 **13px → 16px** 이 된다. 사용자가 실제로 폰으로 보는 화면에서 위반이 사라진다.
- 넓은 화면은 13px 을 유지한다. **이것이 §3 위반이라는 사실을 문서가 숨기지 않는다** — §3 에 조건으로 적히고 이 ADR 이 근거가 된다.
- `--t-aux` 가 미디어쿼리로 바뀌는 유일한 토큰이 된다. `tokens.css` 의 나머지는 전부 고정값이다. **이 파일에 미디어쿼리가 하나 생기는 것이 대가다** — 값을 읽는 사람이 「토큰은 상수다」를 더 이상 못 가정한다.
- **아직 안 고친 것** — 위키·문서·운영 화면의 13px 본문. 각 화면을 옮길 때 같은 토큰으로 간다.
- **포기하는 것** — 스크린샷 하나로 타입 스케일을 설명할 수 없게 됐다. 어느 폭에서 찍었는지를 같이 적어야 한다.
