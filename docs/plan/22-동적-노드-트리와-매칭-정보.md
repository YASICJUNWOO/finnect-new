## 태스크

### T-0125 저장을 노드 트리로 옮긴다

- `wiki_node` 신설 — `(company_id, path)` 유니크 · `category` · `name` · `parent`
- `wiki_fact` 개편 — `node_id` · `key` · `kind(value|event)`. `place`·`place_kind`·`topic`·`slot_key` 를 뺀다
- `company_value` 신설 — 트랙 B. `(company_id, key, 한정어, 시점, 값)` 유니크
- **옛 데이터를 버리지 않는다.** `export.TREE` 가 topic → 경로 표를 이미 들고 있다 — **그 고정 표가 동적 트리의 씨앗이 된다.** value 사실은 `company_value` 로, event 사실은 그 topic 의 자리 경로로 노드를 만들어 옮긴다
- **배포 DB 에도 돌려야 한다**([deploy.md](../deploy.md) §2)

### T-0126 추출을 트랙 둘로 가른다

- `extract.py` → `extract_nodes.py`(A) · `extract_profile.py`(B). 포트는 [ADR-0031](../adr/0031-사실-추출을-포트-뒤로-미루고-스텁으로-배관을-먼저-세운다.md) 그대로
- **A 스키마** — `category`(enum 10) · `node_ref | node_new` · `key_ref | key_new` · `kind` · `value`/`text` · `anchor`
- **B 스키마** — `key`(enum 14) · `value` · `as_of` · `qualifier` · `anchor`
- **anchor 규칙은 안 바뀐다.** 원문에서 그대로 복사 · 못 찾으면 버린다

### T-0127 갈라짐을 막는다

- 프롬프트에 **현재 노드·key·한정어를 번호로** 준다. 경로를 다시 쓰게 하지 않는다
- 코드 그물 — 정규화(공백·구두점 제거) 정확 일치. **같은 호출 결과 안에서 한 번, 기존과 한 번**
- **유사도를 안 쓴다.** 쓰면 다시 비결정론이다

### T-0128 계측 — 신규 노드 수를 센다

**이걸 빼면 위키가 갈라지는 걸 볼 방법이 없다.** 사용자는 노드가 셋인 게 정상인지 모른다.

- 파일마다 「새로 만든 노드 N · 기존에 붙인 것 M」
- 회사마다 노드 수 추이. 파일을 더 올렸는데 노드가 비례해서 늘면 갈라지는 중이다

### T-0129 `.md` 규칙과 마크다운 뷰

- **사실이 붙은 노드가 `.md` 다. 자식이 있든 없든.** 폴더 노트 모양
- `export.py` 의 고정 `TREE` 를 지우고 **DB 의 노드에서 만든다**
- `--export` 는 그대로 돈다. 경로가 동적일 뿐이다

### T-0130 그래프를 방사 트리(마인드맵)로

**궤도·링·구획 호를 걷어낸다.** 저것들은 깊이가 둘로 고정일 때만 성립한다.

```
        중심(회사)
           │
   ┌───┬───┼───┬───┐        카테고리 열. 각도 구간을 갖는다
 회사  제품 시장 …  기록
   │       │
  팀      기능                노드
   │
 (하위)                       깊이 제한 없음
```

- **간선이 보인다.** 부모 → 자식 곡선. 그게 마인드맵이고, 지금 구조가 실제로 트리다
- 카테고리 각도 폭은 **제 아래 잎 수에 비례한다** — `Plan` 이 자라면 넓어진다
- 카테고리 열은 **비어도 뜬다**(`DESIGN.md` §7-5)
- **점마다 이름이 붙는다.** 가지를 따라 라벨이 퍼져서 47개가 들어간다 — 한 링에 몰면 26px 간격이라 못 붙였다
- 색을 안 쓴다. 상태는 채움·선·크기로만

### T-0131 회사 정보 화면 (`/company`)

- 14칸 표. **빈 칸이 물어볼 자리다**([ADR-0028](../adr/0028-초안을-먼저-완성하고-못-채운-자리에서-묻는다.md))
- 시계열은 접고 충돌은 둘 다 편다
- **막대를 만들지 않는다.** 「14칸 중 12칸」으로만 말한다

### T-0132 집필·매칭을 새 어휘로

- `match/profile.py`·`eligible.py` → `company_value` 를 읽는다. **트리를 안 본다**
- `match/rank.py` `NODE_RANK` → 카테고리 10 순서로
- `draft/needs.py` · `item_need.place` → **카테고리 10 + key 14 만 가리킨다.** 동적 경로는 회사마다 달라 양식이 못 가리킨다(`item_need` 에 `company_id` 가 없다)
- `ValueSpec.qualified` 를 지운다 — **읽는 코드가 하나도 없다.** `eligibility` 는 `match/` 로 옮긴다

### T-0133 노드 합치기·나누기 — **다음 회차**

잘못 병합했을 때 되돌릴 도구. 근거가 사실마다 붙어 있어 나누는 것은 가능하다.

**이번에 안 한다.** T-0128 계측을 먼저 돌려 **실제로 얼마나 갈리는지 보고** 만든다 — 하루에 한 번 쓰는 도구인지 스무 번 쓰는 도구인지 모르고 만들면 화면이 틀린다.
