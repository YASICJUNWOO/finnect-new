## 2026-08-21 공고 화면 재설계 — 여섯이 한 묶음이다

[0042](0042-좌측-레일을-넓은-화면에서만-세운다.md) ~ [0047](0047-브레이크포인트를-1024와-640으로-못-박는다.md) 은 시안 하나(`R 적응`)를 제품 코드로 옮기면서 나온 것이고 **전부 현재 `DESIGN.md` 를 벗어난다.** 하나만 되돌리면 나머지가 근거를 잃는다 — 레일을 빼면 1024px 이 쓸모를 잃고([0042](0042-좌측-레일을-넓은-화면에서만-세운다.md) · [0047](0047-브레이크포인트를-1024와-640으로-못-박는다.md)), 브레이크포인트를 빼면 보조 글자를 가를 자가 없다([0044](0044-보조-글자-크기를-폭에-따라-가른다.md)).

판단 근거와 대가는 [`docs/design/mockup/notice/README.md`](../design/mockup/notice/README.md) 에 있다.

## v2 피봇에서 살아남은 결정 둘

전부 뒤집힌 것이 아니다. 이 둘은 v2에서도 그대로다.

**[0003 판별 비노출](0003-판별-비노출.md).** 자격 미달 공고는 여전히 화면에 올리지 않고 요건 대조표를 두지 않는다. [0013](0013-판정-두-층.md)이 노출하기로 한 것은 **적합도의 이유**이지 자격 판정 근거가 아니다. 새 층이 위에 생긴 것이지 이 결정이 뒤집힌 것이 아니다.

**[0005 실제 심사 항목명](0005-실제-심사-항목명.md).** "공고마다 항목명이 다르므로 고정 목록을 코드에 박을 수 없다"가 v2의 "PSST로 고정하지 않는다"와 같은 말이다. 실측이 나중에 이 판단을 강화했다 — 지자체는 자체 양식을 쓴다.

## 유실된 결정

원래 `PRD.md` 12장에 D1~D18 결정이 있었으나 **그 문서가 존재하지 않는다.** 이전 문서가 옮겨 적은 12개(D1, D2, D4, D5, D11~D18)만 남았고 그중 화면 관련은 이 ADR들로 승계했다.

**D3, D6~D10 여섯 개는 내용을 알 수 없다.** 필요해지면 복원이 아니라 새로 결정한다. 자세한 것은 [ADR-0001](0001-정본-문서-체계.md).
