내 사업 위키 — 시안 여덟

축이 둘이다. G 그래프는 패널을 현행으로 고정하고 그래프만 갈고, P 패널은 궤도를 현행으로 고정하고 패널만 간다. 둘 다 바꾼 시안은 없다 — 무엇 때문에 좋아 보이는지 분간이 안 된다. 데이터는 tests/fixtures/wiki/facts.json 118건을 topics.py 라우팅으로 자리 열다섯에 앉힌 것이고 지어낸 값이 없다. 각 화면 하단의 검은 바는 목업 전용이고, 거기 「밀도」로 일곱 장(근거 117) ↔ 두 장(근거 29)을 갈아 끼운다.

대조군

web/components/Orbit.tsx · WikiPanel.tsx 의 현행 재현. 값을 하나도 안 바꿨다 — 알고 있는 결함 둘(빈 자리 이름표 AA 미달 · 구획 라벨이 바깥에만 있음)도 그대로 뒀다. 고치면 대조군이 현행이 아니게 된다.

G · 그래프 — 무엇을 노드로 그리는가

레퍼런스로 받은 화면 셋의 공통점은 재질이 아니라 개수였다(2,387 · 70 · 50). 현행은 자리 15개를 그리고 근거 117개를 클릭 두 번 뒤에 숨긴다 — 재질을 바꿔도 15개는 15개다. 그래서 갈리는 축을 「무엇을 노드로 그리는가」로 잡았다. 패널은 다섯 다 현행이다. 재질과 색은 하단 바의 노브가 정한다 — 시안 축과 직교한다.

P · 패널 — 근거를 어디에 어떻게 두는가

현행 WikiPanel.tsx 는 스스로 「출처를 각주로 빼지 않는다」고 적어 뒀는데 실제로는 <details> 안이라 원문까지 두 번 눌러야 한다. 둘이 그 자리와 안쪽을 같이 다르게 잡는다. 궤도는 둘 다 현행이다. 다섯이었다가 2026-08-21 육안 검토에서 셋을 뺐다 — 무엇이었는지는 README 에 있다.
