# ADR-0017: 위키 그래프를 궤도와 구획으로 배치한다

- 상태: **배치만 대체됨** (→ [ADR-0052](0052-위키-자리를-기획-트리로-바꾸고-구획을-폴더로-세운다.md), 2026-08-22). 자리 열다섯·구획 여섯·안팎 궤도가 바뀌었다. **원칙은 산다** — 자리를 고정한다 · 힘 기반 배치를 안 쓴다 · 각도가 뜻을 갖는다
- 날짜: 2026-08-16
- 근거: [`05_그래프설계근거.md`](evidence/2026-08-16-v2-기획문서/05_그래프설계근거.md)

## 맥락

"노드가 많아지면 정신이 없어질 것 같다"는 지적에서 출발했다. 이 문제에는 이름이 있다. 네트워크 시각화에서 노드와 선이 뒤엉켜 읽을 수 없게 되는 **헤어볼(hairball)** 현상이다.

옵시디언 그래프 뷰가 커뮤니티에서 받는 평가가 그대로 경고다.

1. **200개를 넘으면 헤어볼이 된다.** "시각적으로는 인상적이지만 길찾기에는 쓸모없는" 상태가 된다.
2. **50개 미만일 때만 값이 있다.**
3. 연결이 많은 허브 노트와 보통 노트를 **구분할 수 없다.** 이름으로 검색하지 않으면 특정 노드를 **찾을 수 없다.**

근본 원인은 **노드에 종류가 없기 때문**이다. 모든 노트가 동등하고 모든 링크가 같은 실선이다. 그러니 배치를 물리 시뮬레이션에 맡길 수밖에 없고, 물리는 구조를 만들지 못한다.

## 우리 조건은 다르다

| | 옵시디언 | 우리 |
|---|---|---|
| 노드 종류 | 없음. 전부 노트 | **셋으로 정해져 있다.** 정체성·사업체 정보·사업 내용 |
| 링크 종류 | 없음 | 하위·관련 둘 |
| 노드 수 | 수천~수만 | **열다섯.** 한 사업의 정보량은 한정돼 있다 |
| 스키마 | 자유 | **정해져 있다.** 사업계획서가 요구하는 항목이 곧 스키마 |

**스키마 있는 지식그래프를 만드는 것이므로 배치를 물리에 맡길 이유가 없다.**

## 결정

**힘 기반(force-directed) 자동 배치를 쓰지 않는다. 궤도와 구획으로 자리를 고정한다.**

1. **궤도.** 중심에 정체성 하나, 안쪽 궤도에 사업체 정보 5, 바깥 궤도에 사업 내용 9.
2. **구획.** 각도가 의미를 갖는다. 사업 내용을 네 구획(문제와 해결 · 시장과 고객 · 성과와 자금 · 팀과 계획), 사업체 정보를 두 구획(등록 정보 · 대표와 이력)으로 나눈다. 궤도 위에 구획 라벨을 얹는다.
3. **선은 둘.** 하위(정체성 → 항목)는 실선, 관련(사업 내용끼리)은 얇은 점선. 출처 선은 없앴다 — 근거는 노드에 매달린 청크다([ADR-0014](0014-통합-그래프와-근거-청크.md)).
4. **국소 뷰.** 노드를 누르면 1촌만 남기고 나머지를 죽인다.
5. **점진적 공개와 K-core 벗기기**를 기본 노출을 줄이는 근거로 쓴다.

**색은 종류만 말한다.** 신뢰도나 상태를 색조로 표현하지 않는다. 정리가 필요한 노드는 배지 점을, 비어 있는 노드는 점선 테두리를 쓰되 **테두리 색은 제 종류 색**이다. 색조 하나에 뜻 둘을 얹으면 흐린 초록과 흐린 갈색이 구분되지 않아 종류가 먼저 망가진다. 규칙은 [`../../DESIGN.md`](../../DESIGN.md) §4.1.

**목차 화면과 검색은 만들지 않는다.** 노드가 열다섯이라 화면 하나에 다 들어간다. 목록을 따로 두면 같은 열다섯을 두 번 그리는 것이 된다.

## 결과

- **노드가 늘어도 뭉치지 않는다.** 어느 구획에 들어갈지가 스키마로 정해져 있다.
- **자리가 고정돼 두 번째 볼 때 찾는다.** 물리 배치는 열 때마다 모양이 달라진다.
- **그래프의 역할이 정해졌다.** 구조를 보여주는 개요이자 작업하는 자리다. 노드를 눌러 패널에서 고친다. 역할이 정해지면 "예쁘기만 하다"는 비판이 성립하지 않는다.
- 대가로 **스키마 밖 노드를 놓을 자리가 없다.** F1-4-6으로 새 노드를 만들면 어느 구획에 들어갈지 정해야 한다.
- **다시 열어야 하는 조건은 노드 100개다.** 그래프에서 눈으로 못 찾게 되는 시점이다. 그때 검색과 목록을 같이 다시 이야기한다.
- **200개 규모를 이 구조가 견디는지는 확인되지 않았다.** 지금 열다섯으로 검증한 것을 그 규모의 근거로 쓰지 않는다.
