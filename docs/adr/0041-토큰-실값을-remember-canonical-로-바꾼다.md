# ADR-0041: `DESIGN.md` 를 remember 레퍼런스로 다시 세우고 토큰 실값을 canonical 로 바꾼다

- 상태: 채택됨
- 날짜: 2026-08-21
- 대체하는 것: [ADR-0025](0025-토큰-실값-확정.md) 토큰 실값을 시연에서 받고 타입을 일곱 단계로 정리한다
- 승계하는 것: [ADR-0018](0018-디자인-방향-이관.md) 시각 정본은 `DESIGN.md` · [ADR-0040](0040-에디토리얼-지면형-방향을-쓰지-않는다.md) 에디토리얼 금지 · [ADR-0019](0019-집필의-축을-양식으로.md) 배점에 기대지 않는다 · [ADR-0013](0013-판정-두-층.md) 자격과 적합도를 섞지 않는다
- 쓰는 곳: `web/app/tokens.css` · `web/app/**/*.module.css`

## 맥락

`DESIGN.md` 의 값 출처가 **기획 시연 `redesign.html` 한 벌**이었다. ADR-0025 가 거기서 색·타입·반경을 실측해 §4 를 채웠고, 같은 ADR 의 §10.2 감사가 그 시연이 네 곳에서 문서를 어긴다고 기록했다(적합도 막대 · 배점 · 본문 14/15px · 굵기 500). **값은 받고 화면은 안 받는** 상태였다.

문제는 그 뒤에 남았다. 시연은 한 사람이 하루에 만든 단일 HTML 이고, 토큰이 왜 그 값인지에 대한 근거가 파일 안에 없다. `--r-sm: 10px` 이 10인 이유, `--t-lead: 19px` 이 19인 이유를 물으면 답이 "시연이 그랬다"뿐이다. ADR-0025 자신이 "값이 값을 기다리고 있었다"고 적은 교착을 시연으로 끊은 것인데, 끊은 자리에 근거가 안 남았다.

`oh-my-design` 카탈로그 440건에 **remember(리멤버)** 가 있다. 라이브 표면 두 곳을 2026-07-13 에 계산 스타일로 관측하고 셀렉터별 출처를 붙인 패킷이다. 점수를 매기니 `DESIGN.md` §3 의 확정 아홉을 하드 필터로 걸었을 때 남는 것 중 1위였다 —

- **주 버튼이 근검정인 유일한 후보다.** `action-black #000000`. 상위 점수였던 `toss`·`tossbank`·`coinone`·`jobkorea` 는 파랑(§3-6 금지), `karrot`·`kakao` 계열은 오렌지·옐로(§3-5 금지)라 전부 떨어졌다.
- 조밀하고 크롬 없는 목록. finnect 가 "표 중심 업무 도구"인 것과 같다.
- Pretendard. 이미 쓰고 있다.
- 한국어 지배 voice, register `senior-colleague`, 짧은 문장.
- 문서 자체가 **증거 경계형**이다. 모든 주장에 관측 표면을 달고 "captured / baseline only / not evidence that" 으로 일반화를 거부한다. finnect 의 "사실 주장에는 근거 링크를 붙인다"·"몇 건을 눈으로 봤는지 함께 적는다" 와 같은 계열이다.

## 결정

**`DESIGN.md` 를 remember 의 절 구조로 다시 세우고, remember canonical 에 대응이 있는 토큰만 그 값으로 바꾼다.**

대응이 있는 축:

| 토큰 | 전 | 후 | remember |
|---|---|---|---|
| `--action` | (없음) | **`#000`** | `action-black` |
| `--ink` | `#16181b` | **`#222`** | `foreground` |
| `--ink-3` | `#949aa2` | **`#6b7280`** | `muted` 를 **안 받았다** — 아래 3번 |
| `--line` | `#e9eaec` | **`#d4d4d4`** | `hairline` |
| `--quiet` | `#f4f5f6` | **`#f2f2f2`** | `input-surface` |
| `--r-sm` | `10px` | **`4px`** | `rounded.sm` |
| `--r-md` | (없음) | **`6px`** | `rounded.md` |
| `--r` | `16px` | **`8px`** | `rounded.lg` |
| `--t-title` / `--lh-title` | `24px` / `1.35` | **`20px` / `1.3`** | `heading` |
| `--t-lead` / `--lh-lead` | `19px` / `1.5` | **`16px` / `1.45`** | `card-title` |
| `--lh-body` | `1.6` | **`1.45`** | `body` |
| `--surface` · `--t-body` · `--s1`~`--s5` | — | **안 바뀜** | 이미 같았다 |

**대응이 없는 축은 손대지 않는다.** `--canvas`(회색 캔버스) · `--ink-2` · `--ink-4` · `--line-2` · 상태색 여섯 · 노드 분류색 셋 · `--t-caption`·`--t-small`·`--t-display`·`--t-hero` · `--r-pill` · `--w-bold` · `--tracking-title` · `--shadow-raised`. remember 패킷이 관측하지 않은 것이고, **관측하지 않은 것을 채우지 않는 것이 remember 의 규율**이라 그 규율을 그대로 적용한 결과다. `tokens.css` 주석에 축마다 `remember` 인지 `관측 밖` 인지 적었다.

### 세 가지를 명시적으로 안 가져왔다

1. **`corporate-orange #fc5d11`.** remember 자신이 "corporate marketing 표면 한정이고 career 제품의 기본 동작색이라는 증거가 아니다"라고 못 박았다. §7(구 §3-5)이 오렌지를 브랜드 액센트로 쓰는 것을 금지하는 것과 결론이 같다.
2. **Founders Grotesk Condensed.** remember 패킷에서도 출처 미해결이고 finnect 는 서체를 하나로 간다.
3. **`muted #808080` 자체.** remember 는 이 값을 **입력 플레이스홀더** 관측값으로 적었다. 처음에는 플레이스홀더 등급인 `--ink-3` 에 그대로 넣었는데, 넣고 나서 두 가지가 걸렸다.

   첫째, **`::placeholder` 가 우리 CSS 에 하나도 없다.** `--ink-3` 14곳이 전부 텍스트다. 둘째, **12·13px 도 WCAG 기준으로는 일반 텍스트다** — large text 면제는 18.66px bold 또는 24px 부터라 4.5:1 이 그대로 걸린다. 14곳의 크기 분포는 13px 8곳 · 상속 3곳 · 12px 2곳 · 16px 1곳이고 `#808080`(3.95:1)에서는 **전부 미달**이다.

   셋째가 결정적이다. **remember 는 흰 field 위에서 잰 값이고 우리 캔버스는 `#f7f7f8` 회색이다.** 같은 `#808080` 이 우리 화면에서는 3.69:1 로 더 내려간다. 고전 AA 회색 `#767676` 조차 흰 면 4.54:1 · 캔버스 4.24:1 이라 우리 캔버스를 못 넘는다.

   그래서 **`#6b7280`** 으로 갔다 — 흰 면 4.83:1 · 캔버스 4.52:1 로 양쪽을 넘는 가장 밝은 값이다. `--ink-2`(#5f656d, 5.88:1)와 구분되는 셋째 단계가 유지된다. **remember canonical 에서 의도적으로 벗어난 유일한 색이고, 벗어난 이유는 레퍼런스가 다른 바탕에서 관측됐기 때문이다.** 옛 `#949aa2` 는 2.84:1 이었으므로 어느 쪽이든 개선이다.

## 결과

**얻은 것.** 값마다 관측 표면과 날짜가 붙었다. `--r-sm` 이 4인 이유가 "career-postings 의 필터·검색·인증 컨트롤 네 곳에서 4px 이 관측됐다"가 됐다. 동작 검정과 읽는 글자가 분리돼 주 버튼이 본문보다 확실히 앞으로 나온다 — 이것이 remember 의 첫째 특징이고 §3-4 가 원래 하려던 말이다.

**잃은 것.** ADR-0025 가 세운 **타입 긴장이 줄었다.** 일곱 단계의 범위가 3.7배(12→44)였는데, remember 관측 셋만 보면 16/16/20 이라 1.25배다. `--t-lead` 가 `--t-body` 와 같아졌다. remember 에서는 이것이 의도다("카드를 띄우지 않고 글자로 미는 목록 리듬") — **다만 `design-anti-slop` V2(타입 위계 없음)에 다시 가까워진 것도 사실이다.** 관측 밖인 12·13·32·44 를 유지해 범위 자체는 지켰지만, 그 넷은 이제 remember 근거가 없다.

**되돌리려면** `DESIGN_DEPRECATED.md` 가 그대로 있다. 옛 값 전부가 거기 §4 에 남아 있다.

## 검증

```bash
cd web && npm run lint && npm run typecheck && npm run build
grep -rn 'var(--action)' app          # 주 버튼 넷. 로고 마크(.mark)는 여기 없어야 한다
grep -rn '#[0-9a-fA-F]\{3,6\}' app --include=*.module.css   # 0건. 색 리터럴을 컴포넌트에 쓰지 않는다
```

**화면을 눈으로 봐야 한다.** 반경이 10→4 · 16→8 로 내려가고 `--t-title` 이 24→20 으로 내려가는 것은 전 화면에 걸친 변화다. 명령만으로는 안 잡힌다.
