# T-0002: 데모 전제 → 제품 전제

- 상태: 대기
- 단계: [plan/04](../plan/04-화면.md)
- 선행: —

## 무엇을

화면 문서에 남은 데모 전제를 제품 전제로 바꾼다.

## 왜

이전 기획서는 **단일 HTML 파일로 만드는 시연용 데모**를 전제하고 있었다.

| 전제 | 실제 제품에서는 |
|------|----------------|
| 단일 HTML, 외부 요청 없음 | 서버·API 있음 |
| 목업 데이터가 채워진 상태로 시작 | 실제 수집 데이터 |
| 공고는 사전 색인된 **스냅샷** | F0이 주기적으로 갱신 |
| 로그인 없이 세션 단위 | 프로필 저장이 필요 |

[ADR-0008](../adr/0008-제품-범위-확대.md)로 범위가 제품으로 바뀌면서 이 전제들이 사실이 아니게 됐다.

**대부분은 이미 재구성 과정에서 정리됐다.** 남은 것은 `design/prototype-data.md`의 위치 정리와 프로필 저장 방식이다.

## 완료 조건

- `design/prototype-data.md`가 "시안용 예시"임이 화면 구현 코드에서도 명확하다. 실제 데이터와 섞이지 않는다
- 프로필 저장 방식이 정해진다. 계정 없이 어떻게 프로필을 유지할지 — 로컬 저장인지, 익명 세션인지
- 색인 갱신 주기가 정해지고 화면에 표시할지 정한다. 공고가 갱신되면 목록이 바뀌는데 사용자에게 알릴지
