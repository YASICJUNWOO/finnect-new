# design/wireframes.md — 화면 배치

화면이 담는 기능은 [`../SPEC.md`](../SPEC.md) §5에 있다. 여기는 배치만 다룬다.
그림에 쓰인 값은 예시이며 실제 값은 [`prototype-data.md`](prototype-data.md)에 있다.

> ⚠️ **S2와 S3의 배점 표기는 확정되지 않았다.** 실측 결과 초기창업패키지·창업도약패키지는 배점을 공개하지 않는다(창업 분야 전체 명시율 25%). 아래 그림의 배점 막대는 **배점을 공개하는 공고에서만** 그린다. 미공개 공고의 대체 배치는 [ADR-0010](../adr/0010-배점-전제-폐기.md)에서 정한다.

배점을 공개하는 공고에서는 평가 항목 표에 배점 열과 막대를 덧붙인다.

```
│              ├────────────────────────────────────────────────────────────┤

│              │                                                            │
│              │  1. 이 공고는 지정 양식을 쓰고 15페이지 내외로 씁니다.      │
│              │     양식을 벗어나면 평가대상에서 제외됩니다.                │
│              │  2. 업력 1년 4개월은 이 사업의 지원 취지에 맞는 구간이라    │

│              │  ▸ 심사 항목과 평가 관점                        [ 펼치기 ] │
│              │  ▸ 목차 구조와 분량                              [ 펼치기 ] │
│              │  ▾ 강조할 지점                                             │
│              │     ┌──────────────────────────────────────────────────┐  │
│              │     │ 실현가능성                                        │  │
│              │     │ 업력 1년 4개월 구간의 실행 실적을 앞세웁니다.     │  │
│              │     ├──────────────────────────────────────────────────┤  │
│              │     │ 문제인식                                          │  │
│              │     │ 소프트웨어 개발업은 제한 업종이 아니므로 기술     │  │

│              │  ▾ 아직 모르는 것                                          │

│              │     2. 기술 구현 방식과 개발 단계     실현가능성           │
│              │     3. 수익 모델과 매출 계획          성장전략             │
```

결론 3줄이 먼저 오고 근거 블록은 접혀 있다. 아직 모르는 것의 각 줄에 심사 항목이 붙어 다음 단계 질문의 근거가 된다.

> ⚠️ 원래 이 화면은 **배점 순 정렬**을 전제했고 결론 1번이 "배점이 가장 큰 항목은…"이었다. 배점이 없는 공고에서는 성립하지 않아 위와 같이 양식·분량 축으로 잠정 교체했다. 확정은 [ADR-0010](../adr/0010-배점-전제-폐기.md).

```
│          │               │                                               │

│          │   대기        │                                               │
│          │               │ ▌생성 중 ...                                  │
│          │ ──────────    │                                               │

└──────────┴───────────────┴───────────────────────────────────────────────┘
```

컨텍스트 바 한 줄에 항목명, 분량, 원문 링크, 2단계 답변 펼치기를 넣는다. 답변을 펼쳐 고치면 그 항목만 다시 쓴다.

**우측 근거 패널을 두지 않는다.** 집필 중 계속 봐야 하는 것은 분량과 항목이고 그건 한 줄이면 된다.


각 행 마지막 줄이 **다음 할 일과 버튼**이다. 제출함 섹션의 안내가 제출을 우리가 대신하지 않는다는 사실을 알린다.

**상태를 자동으로 바꾸지 않는다.** 제출이 범위 밖이라 우리가 알 방법이 없고, 안다고 표시하면 거짓이 된다.
