# docs/ — 문서 지도

창업 지원사업 **자격 판별**과 **사업계획서 집필**을 잇는 제품이다.

```
docs/
├─ SPEC.md            제품 정본 — 무엇을 만드는가
├─ api-contract.md    제품 API 계약 — web/ 과 src/finnect/api/ 사이의 유일한 경계
├─ deploy.md          배포 절차 — 올라가는 것은 읽기 경로뿐이다
├─ dataset.md         공고 코퍼스 초기화·재적재 일곱 단계 (전량 기준 · 로컬 전용)
├─ 초기화.md          같은 절차의 좁은 경로 — 개발용으로 작게 세운다
├─ 초안-집필-구조.md   src/finnect/draft/ 를 읽어 적은 설명 — **코드가 바뀌면 먼저 낡는다**
├─ adr/               결정 — 왜 그렇게 정했는가
├─ plan/              계획과 태스크 — 어떤 순서로 만드는가, 지금 무엇이 막혀 있는가
├─ design/            v1 화면 산출물 — **대체됐다.** 정본은 레포 루트 DESIGN.md 다
└─ archive/           폐기된 방향
```

---

## 어디부터 읽나

| 목적 | 읽을 것 |
|------|---------|
| 제품이 뭔지 알고 싶다 | [`SPEC.md`](SPEC.md) — 이것 하나면 된다 |
| 지금 뭘 해야 하나 | [`plan/README.md`](plan/README.md) 보드 |
| 왜 이렇게 정했나 | [`adr/README.md`](adr/README.md) 목록 |
| 화면을 만들려면 | 레포 루트 [`DESIGN.md`](../DESIGN.md) — **`design/` 이 아니다**([ADR-0018](adr/0018-디자인-방향-이관.md)) |
| 화면과 API 를 잇는다 | [`api-contract.md`](api-contract.md). 정본은 코드(`api/schemas.py`)이고 이 문서가 뜻을 적는다 |
| 코퍼스를 다시 세운다 | 전량은 [`dataset.md`](dataset.md), 개발용으로 작게는 [`초기화.md`](초기화.md) |
| 배포한다 | [`deploy.md`](deploy.md) |
| 전체 순서 | [`plan/README.md`](plan/README.md) |

**충돌 시 `SPEC.md`가 우선한다.** 단 **시각에 한해서는 레포 루트 `DESIGN.md` 가 이긴다**([ADR-0018](adr/0018-디자인-방향-이관.md)).

**진행 상태는 [`plan/README.md`](plan/README.md)가 정본이다.** 무엇이 막혀 있고 지금 무엇을 할 수 있는지는 거기 한 곳에만 적는다. 이 문서에 옮겨 적지 않는다 — 두 곳에 적으면 한 곳이 반드시 거짓말을 한다. **2026-08-24 루트 `CLAUDE.md` 가 그 예로 걸렸다** — 계획 상태를 옮겨 적어 두고 닫힌 계획 넷을 열려 있다고 말하고 있었다. 그 자리는 이제 여기를 가리킨다.

**코드가 있다.** `src/finnect/` 에 모듈 열, `web/` 에 Next.js 앱, `tests/` 에 테스트가 있다. 이 디렉터리가 문서만 담을 뿐이다. `spike/` 는 실측용 **버리는 코드**이고 `notice-filter/` 는 제품 밖에 사는 자격 층 판정기다.

## 문서를 쓰는 규칙

1. **사실 주장에는 근거 링크를 붙인다.** 근거 없는 주장은 `SPEC.md` §8에 날짜와 함께 올리거나, 올릴 수 없으면 쓰지 않는다.
2. **결정은 ADR에 남긴다.** ADR에 없는 결정은 결정이 아니라 관성이다.
3. **틀린 문서를 미리 쓰지 않는다.** 계층별 상세 사양은 코퍼스를 보고 나서 쓴다([plan/README.md](plan/README.md)).
4. **자동 판정 수치를 육안 검증 없이 쓰지 않는다.** 실측에서 배점 탐지기가 30% → 45% → 25%로 갔고 앞의 둘은 오탐이었다.

이 규칙들은 전부 실제로 당해서 생겼다. 배경은 [ADR-0001](adr/0001-정본-문서-체계.md)에 있다.
