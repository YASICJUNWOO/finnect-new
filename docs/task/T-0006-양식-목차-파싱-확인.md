# T-0006: 양식 목차 파싱 가능성 확인

- 상태: 대기
- 단계: [plan/00](../plan/00-미결-해소.md)
- 선행: —

## 무엇을

사업계획서 지정 양식(별첨1)에서 **목차 항목과 세부항목을 기계적으로 구조화**할 수 있는지 확인한다.

표본은 최소 10건. 초기창업패키지·창업도약패키지 외에 지자체 사업도 섞는다.

## 왜

[ADR-0010](../adr/0010-배점-전제-폐기.md)의 2안(축을 배점에서 양식으로 이동)을 고르면 **이것이 새 전제가 된다.** 배점 파싱이 전제였던 자리를 양식 파싱이 대신한다.

실측에서는 텍스트만 뽑았고 구조화는 해보지 않았다. 텍스트가 나오는 것과 목차 계층을 복원하는 것은 다른 문제다.

초기창업패키지 양식은 이런 구조였다.

```
1. 문제 인식 (Problem)   →  1. 창업 아이템의 필요성
                             - 국내·외 시장 현황 및 문제점
                             - 개발 필요성 등
```

**세부항목이 사실상 "무엇을 쓰라"는 지시문이다.** 이게 구조화되면 F6 질문 생성에 그대로 쓸 수 있다.

## 완료 조건

- 표본 10건 이상에서 목차 구조화 성공률을 잰다
- **결과를 눈으로 검증한다.** 자동 판정 수치만으로 결론 내지 않는다
- 결과를 `adr/evidence/`에 남긴다
- ADR-0010의 2안 실현 가능성에 대한 판단이 선다
