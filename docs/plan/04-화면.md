## 이 단계에서 확정할 것

### S2의 평가 블록

배점이 없는 공고가 다수라 **배점 막대를 조건부로 그려야 한다.** 배점이 있을 때와 없을 때의 배치를 둘 다 만든다.

없을 때는 평가 항목 이름 + 평가 관점 + 단계 + 커트라인 + 가점을 보여준다. 실측에서 이 값들은 확보되는 것을 확인했다.

### 데모 전제 제거

`design/prototype-data.md`가 예시 데이터를 담고 있다. 화면이 실제 색인 위에서 돌게 되면 이 데이터는 시안용으로만 남는다.

→ [T-0002](../task/T-0002-데모-전제-교체.md)

### 빈 상태

S1이 0건일 때 "내 정보를 채우면 판단할 수 있는 공고가 늘어난다"고 안내한다. 판별을 화면에 안 보여주므로 **0건이 나오면 사용자는 이유를 모른다.** 이 화면이 유일한 안내다.
