# ADR-0067: 운영 화면을 HTTP Basic 으로 막는다 — 테스터가 들어오면서 열린 문이 됐다

- 상태: 채택됨
- 날짜: 2026-08-24
- 뒤집는 것: [ADR-0027](0027-운영-화면을-nextjs로-옮긴다.md)이 정직하게 적어 둔 **"인증이 없다. `/admin` 은 누구나 연다"** 한 줄. 조회 화면 넷을 Next.js 로 옮긴 결정은 그대로다
- 근거: [ADR-0035](0035-api와-워커를-자체-서버로-내리고-vercel은-화면만-맡는다.md) 토큰 · [ADR-0065](0065-수집-실행을-배포-api-에-연다.md) 실행 토큰 · [ADR-0066](0066-베타-테스터를-이름과-비밀번호로-가른다.md) 베타 게이트

## 맥락

`/admin` 이 누구나 여는 화면인 것은 처음부터 알고 있었고 ADR-0027 이 그렇게 적어 뒀다. **보는 사람이 나 혼자였기 때문에 성립하던 상태다.**

ADR-0066 이 외부 테스터를 받으면서 그 전제가 깨졌다. 그리고 문제가 하나 더 있다 — `web/app/(product)/layout.tsx` 가 **모든 제품 화면 상단에 「운영 도구」 링크를 그린다.** 좁은 화면에서도 안 숨긴다(그 결정의 근거는 "폰에서 `/admin` 가는 문이 사라지면 기능 축소"였는데, 그것도 보는 사람이 하나일 때 이야기다). **테스터가 들어오면 헤더에 그 링크가 보이고, 누르면 수집 기록·해독률·공고 원본이 다 열린다.**

**무엇이 새는지 정확히 적는다.** 다른 테스터의 위키·올린 파일·회사 정보는 **안 샌다** — 운영 화면 넷이 부르는 것은 `/api/admin/notices`·`attachments`·`ingest` 뿐이고 전부 공고 코퍼스와 운영 기록이다. 새는 것은 **우리 내부 사정**이다: 수집이 몇 건 실패했는지, 해독률이 얼마인지, 정부 API 가 준 원본 필드가 무엇인지.

**API 쪽은 이미 막혀 있었다.** `api_token`(ADR-0035)이 설정돼 있어서 `/api/admin/*` 를 밖에서 직접 부를 수 없다. 뚫린 것은 **화면**이고, 그 화면은 토큰을 들고 있는 Next.js 서버가 대신 불러다 준다.

## 결정

**1. HTTP Basic 을 쓴다.** 만들 화면이 없고 브라우저가 창을 띄운다.

`/enter`(ADR-0066) 같은 폼을 하나 더 만들지 않는다 — **운영 도구에 제품 수준의 공을 들이는 셀이고**, DESIGN.md §9 가 "두 표면의 용도를 하나의 일반 시스템으로 뭉치지 않는다"고 한 자리다. 대가는 **로그아웃이 없다는 것**이다(브라우저를 닫아야 풀린다). 운영자가 자기 기기에서 보는 화면이라 받아들인다.

**2. 문 둘을 겹친다 — 화면과 API 를 따로 막는다.**

| | 무엇이 막나 | 무엇을 묻나 |
|---|---|---|
| `web/proxy.ts` | `/admin/*` · `/api/admin/*` | 운영 화면을 봐도 되나 |
| `api/app.py` `require_admin` | `/api/admin/*` | 운영 자료를 받아도 되나 |

**화면만 막으면 안 된다** — 라우트 핸들러(`web/app/api/admin/ingest/run/[source]`)가 그대로 열려 있어서 `POST` 를 직접 칠 수 있다. **API 만 막아도 안 된다** — 화면이 토큰을 들고 있어서 그 화면을 여는 사람은 이미 통과한 뒤다. 한 겹이 뚫려도 다른 겹이 남는다.

**3. 접두사 하나로 판단한다.** `_ADMIN_PREFIX = "/api/admin/"` 이고 화면 쪽도 같은 문자열이다.

라우트마다 `Depends` 를 다는 방법을 안 쓴다 — **새 운영 경로가 생긴 날 하나가 빠지고, 그 하나만 열려 있다.** 접두사로 보면 잊을 수가 없다. `tests/test_admin_auth.py` 가 양방향으로 잠근다: `tags=["admin"]` 인 경로가 전부 접두사 아래인가, 접두사 아래가 전부 운영 경로인가.

**4. 자격이 비어 있으면 503 이다. 열지 않는다.**

`api_token` 은 비어 있으면 검사를 **끄는데**(로컬 편의) 이건 반대다. `ingest_trigger_token`(ADR-0065)과 같은 규칙이고 이유도 같다 — **이 경로는 사용자 것이 아니라서, 설정을 잊었을 때 열리는 쪽이 아니라 닫히는 쪽이어야 한다.**

**5. 비밀번호를 레포에 안 넣는다.** 값은 `~/.config/finnect/api.env`(백엔드)와 Vercel 환경변수(화면)에만 있다. `ADMIN_USER`·`ADMIN_PASSWORD` 이고, 로컬 화면은 `web/.env.local` 이다(`.gitignore` 의 `.env.*` 가 잡는다).

**6. `require_admin` 이 `require_token` 보다 안쪽이다.** 바깥 문이 "이 API 에 말을 걸어도 되나"이고 안쪽이 "운영 자료를 봐도 되나"다 — **토큰이 없는 요청은 Basic 창을 보기 전에 막힌다.** Starlette 은 나중에 더한 미들웨어가 바깥이라 소스에서 먼저 더해서 그렇게 만든다.

## 결과

- **ADR-0027 의 "인증이 없다" 한 줄이 유효기간을 다했다.** 나머지(조회 화면 넷을 Next.js 로, `src/finnect/admin/` 에 수집 실행만 남김)는 그대로다.
- **토큰이 이제 셋이다.** `api_token`(서버 대 서버) · `ingest_trigger_token`(버튼 하나) · `admin_user`/`admin_password`(운영 자료). 셋 다 다른 것을 묻는다 — 합치면 "수집을 돌려도 되는 사람"과 "기록을 봐도 되는 사람"이 같아진다.
- **「운영 도구」 링크는 그대로 있다.** 테스터가 누르면 브라우저 비밀번호 창을 본다 — 막히기는 하지만 보기 좋지 않다. 숨기는 것은 시각 결정이라 따로 정한다.
- **로그아웃이 없다.** 브라우저를 닫아야 풀린다. 자격을 바꾸려면 환경변수를 갈고 서비스를 재시작한다 — `proxy.ts` 가 Node.js 런타임이라(Next 16 기본) **다시 빌드하지 않아도 된다.** `FINNECT_API` 가 빌드에 박히는 것과 반대다.
- **Vercel 에 값을 안 넣으면 배포본 `/admin` 이 503 이다.** 열려 있는 것보다 낫지만, 넣기 전까지 운영자도 못 본다.
