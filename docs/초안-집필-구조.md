# 초안 집필은 어떻게 도나 (F6 · G 계층)

> 2026-08-22 코드를 읽어 적은 **설명 문서**다. 진행 상태의 정본은 [plan/16](plan/16-항목마다-초안을-쓴다.md)이고,
> 결정의 정본은 ADR 이다. 여기 적힌 것은 `src/finnect/draft/` 일곱 파일의 현재 모양이라
> **코드가 바뀌면 이 문서가 먼저 낡는다.**

예시 데이터는 [`tests/test_draft_allot.py`](../tests/test_draft_allot.py) · [`tests/test_draft_write.py`](../tests/test_draft_write.py)의


## ①-a 양식 읽기 — `needs.py`

양식 하나를 **통째로 한 번** 읽는다. 항목 제목만으로는 못 정한다.

**넣는 것** ([`needs.py` `_user_prompt`](../src/finnect/draft/needs.py))

```
양식 이름: 서식 3 사업계획서

--- 항목 ---
[0] 2-1 사업수행 배경 및 목적
      지시문: 배경 및 필요성, 과제추진 목적, 규모 및 내용 등에 대하여 자세하게 기술
      분량: 1page 이내
[1] 2-2 지원필요성
      지시문: 애로사항 중심으로 필요성, 시의성을 기술
[2] 1 사업 개요
      지시문: 위 내용을 200자 이내로 요약
```

**받는 것** — 스키마가 `place` 를 `PLACES` 스물넷의 `enum` 으로 막는다

```json
{"items": [
   {"index": 0, "needs": [{"place": "Customer", "required": true},
                          {"place": "Company",  "required": true},
                          {"place": "revenue",  "required": false}],
    "summary_of_others": false},
   {"index": 1, "needs": [{"place": "Customer", "required": true}],
    "summary_of_others": false},
   {"index": 2, "needs": [], "summary_of_others": true}],
 "overlaps": [{"a": 0, "b": 1, "note": "둘 다 필요성을 요구한다"}]}
```

**요점** — `[2]` 가 `summary_of_others: true` 다. 되풀이하라고 있는 자리라 아래 ①-b·⑤ 가 **건드리지 않는다.** `overlaps` 의 `(0,1)` 이 ①-b 가 다툴 유일한 근거다.

`{"place": "traction"}` 처럼 목록 밖 이름이 오면 버리고 `dropped` 에 센다 — 위키에 없는 자리를 요구하면 그 항목은 영원히 "못 채움"이 된다.

**한 번만 묻는다.** `document` 가 sha256 키라 다른 공고가 같은 양식을 붙여도, 다른 회사가 신청해도 이 결과를 그대로 쓴다.

## ①-b 배분 — `allot.py`

**후보 계산은 코드다.** 사실의 `place` 를 조상 전부에 걸어 둔다([`allot.py` `_index`](../src/finnect/draft/allot.py)).

```
사실 #11 place = "Customer/고객문제"
   → _ancestors → ["Customer", "Customer/고객문제"]
   → item_need.place 가 "Customer" 인 항목이 이 사실을 후보로 갖는다
```

```
              후보 사실                      겹침 쌍?
[0] 2-1   #11 #12 (Customer) · #13 (Company) · #-7 (revenue)
[1] 2-2   #11 #12 (Customer)                              ← (0,1) 이 쌍이다
[2] 요약  —                                                 summary → 제외
```

**다투는 것** = 쌍 안에서 양쪽 다 가진 것 = `#11 #12`. `#13`·`#-7` 은 `[1]` 의 자리가 아니라 애초에 안 다툰다.

**LLM 에 넣는 것** — 다투는 둘만 간다

```
--- 후보 항목 ---
[0] 2-1 사업수행 배경 및 목적
      지시문: 배경 및 필요성, 과제추진 목적, 규모 및 내용 …
[1] 2-2 지원필요성
      지시문: 애로사항 중심으로 필요성, 시의성을 기술

--- 다투는 사실 ---
#11 (Customer/고객문제) 철강 경기 침체로 수주가 끊겼다   → 후보 [0] · [1]
#12 (Customer/고객문제) 설비 노후로 불량률이 올랐다      → 후보 [0] · [1]
```

```json
{"assign": [{"fact": 11, "item": 1, "why": "애로사항이다"},
            {"fact": 12, "item": 0, "why": "배경이다"}]}
```

**결과**

```
[0] 2-1  →  #12 #13 #-7          missing: []
[1] 2-2  →  #11                  missing: []
```

**세 가지가 여기서 갈린다.**

- 겹침 쌍이 아예 없으면 → **LLM 을 안 부른다.** `[0]` 이 `#11 #12 #13`, `[1]` 이 `#11 #12` 를 그냥 다 쓴다([`tests/test_draft_allot.py`](../tests/test_draft_allot.py) `test_쌍이_없으면_LLM_을_안_부른다`)
- 모델이 `#11` 의 주인을 안 정하면 → **아무도 안 쓴다.** 양쪽 다 주면 중복이 그대로 나오고, 임의로 주면 그 선택을 설명할 수 없다
- 항목이 `Market` 을 요구하는데 위키에 `Market/…` 사실이 0건이면 → `missing: ["Market"]`. **뺄셈이다**([`allot.py` `_missing`](../src/finnect/draft/allot.py)) — 이 값이 화면의 "못 채운 곳"이고 [ADR-0028](adr/0028-초안을-먼저-완성하고-못-채운-자리에서-묻는다.md) 적립 루프의 입구다

## ② 재료 조립 — `service.py`

배분된 id 로 근거 청크 원문까지 끌어온다. **표 둘을 정수 하나로 합친다.**

```
wiki_fact.id = 11        → 재료 공간  #11    (트랙 A · 서술)
company_value.id = 7     → 재료 공간  #-7    (트랙 B · 매칭 정보 열넷)
```

부호를 뒤집는다([`refs.py`](../src/finnect/draft/refs.py)). 두 표 다 1부터 시작하는 자동증가라 그냥 섞으면 `#3` 이 어느 표의 3인지 알 수 없다. `id + 10**9` 를 안 쓰는 이유는 **언젠가 그 경계를 넘고, 넘는 날 조용히 틀려서**다.

값은 라벨을 붙여서 넣는다([`service.py` `_value_text`](../src/finnect/draft/service.py)) — 저장값 `241000000` 만 주면 집필이 단위를 지어낸다.

```
company_value(key=revenue, value=241000000, as_of=2024-12-31)
   → "매출액 2억 4,100만원 — 2024-12-31 기준"
```

## ③ 집필 — `write.py`

항목 하나 → 문단 여럿. **항목당 LLM 1회, 도구 없음.**

**넣는 것** ([`write.py` `_user_prompt`](../src/finnect/draft/write.py))

```
항목: 2-1 사업수행 배경 및 목적
양식이 요구한 것: 배경 및 필요성, 과제추진 목적, 규모 및 내용 등에 대하여 자세하게 기술
분량: 1page 이내

--- 공고가 준 값 ---
사업명: 2026년 성남시 중소기업 기술개발 지원사업
수행기관: 성남산업진흥원
접수기간: 2026-08-01 ~ 2026-09-15
공고 내용: … 기업당 최대 5,000만원 … (3,000자까지)

--- 쓸 수 있는 사실 ---
#12 [Customer/고객문제] 설비 노후로 불량률이 올랐다
      원문: 2023년 하반기 들어 불량률이 8%까지 올랐고
#13 [Company/정체성] (주)다시로는 중고 설비를 되살린다
#-7 [revenue] 매출액 2억 4,100만원 — 2024-12-31 기준
      원문: 매출액 24,100천원
```

**받는 것** — 스키마의 `facts` 가 `{"enum": [12, 13, -7]}` 이라 **없는 사실을 못 든다**

```json
{"paragraphs": [
  {"text": "(주)다시로는 중고 설비를 되살리는 …", "facts": [13]},
  {"text": "2024년 매출액은 2억 4,100만원이다. …", "facts": [-7]}]}
```

**공고 값을 안 넘기면 자기 자신을 막는다.** `최대 5,000만원` 이 재료에 없으면 ④가 그 금액을 지운다([`service.py` `_notice_material`](../src/finnect/draft/service.py)).

**`facts` 가 빈 문단은 버린다.** 도입·전환·맺음 문장이 그렇게 온다 — 남기면 근거 없는 문단이 생기고, `wiki_evidence` 없는 `wiki_fact` 를 안 만드는 규율과 어긋난다.

## ④ 검증 — `write.verify()`

**환각을 프롬프트가 아니라 코드로 막는다.** 출력의 숫자·고유명사를 재료 뭉치에 대조한다.

```
재료:  "매출액 24,100천원"

"2024년 매출은 24,100천원입니다."   → 그대로              killed = []
"매출 24,100 천원"                  → 그대로              공백·쉼표 무시
"매출은 98,700천원입니다."          → "매출은 [확인 필요]천원입니다."
                                                          killed = ["98,700"]
```

**문장을 통째로 안 지운다.** `"2024년 매출은 98,700천원까지 올랐습니다"` 는 앞부분이 남는다 — 지우면 무엇이 문제였는지 화면에서 사라진다.

**조사를 떼고 한 번 더 본다**([`write.py` `_in_corpus`](../src/finnect/draft/write.py))

```
출력 "(주)다시로는"   재료 "(주)다시로가"
   → 글자가 달라 첫 대조 실패
   → 뒤 1글자 떼고 "(주)다시로" 재대조 → 통과
```

안 하면 **맞는 회사 이름이 지워진다.**

**한 자리 숫자는 안 본다**([`write.py` `_is_claim`](../src/finnect/draft/write.py)) — `1. 첫째` 의 `1` 까지 잡으면 목록이 깨진다. 두 자리 이상이거나 뒤에 단위(`원억만천백십명년…`)가 붙어야 사실 주장으로 본다.

## ⑤ 중복 점검 — `dedupe.py`

**코드가 먼저다.** 두 항목이 같은 청크를 근거로 들면 그 자체가 신호다.

```
[0-1] "2024년 매출액은 2억 4,100만원이다"     chunk_ids = (5,)
[1-0] "매출 2억대에서 정체돼 있어 …"          chunk_ids = (5, 9)
   → 교집합 {5} → Clash(found_by="chunk")     LLM 안 부른다
```

같은 항목 안의 문단끼리는 안 본다 — 한 근거를 여러 문단에서 푸는 것은 중복이 아니라 전개다.

**코드가 못 잡는 것**만 문서당 LLM 1회가 본다. 사업자등록증과 회사소개서에 같은 내용이 적혀 있으면 **근거는 다르고 문단은 같다.** 이미 잡은 쌍은 `known` 으로 넘겨 다시 안 묻는다.

지금은 **세기만 한다.** 겹친 항목 자동 재작성은 사람이 볼 화면이 없으면 소리 없이 본문을 바꾸는 일이다.

## 곁가지 — 분량 (`limits.py`)

```
"2,000자 이내"    본문 2,340자  →  over          "2,000자 이내 인데 2,340 다 (340 넘음)"
"50페이지 내외"                 →  unmeasurable  "쪽 수는 글자로 환산하지 않는다"
"1,000자 내외"    본문 1,180자  →  unmeasurable  "`내외` 라 초과 판정을 안 한다 (지금 1,180)"
```

쪽 수를 환산하려면 A4 한 장에 한글 몇 자인지를 정해야 하는데 그건 서체·여백이 정한다. 관례 1,800자는 근거가 아니다. **넘어도 다시 쓰지 않는다** — 표시만 한다.

## 저장된 모양

```
draft                allotment = {"4711": [12, 13, -7], "4712": [11]}
  draft_item         document_item 4711 · ordinal 3 · status "drafted"
    body             "(주)다시로는 …\n\n2024년 매출액은 …"
    draft_evidence   paragraph 0 · fact_id 13 · chunk_id 4
    draft_value_ev.  paragraph 1 · value_id 7 · chunk_id 5     ← 트랙 B 는 표가 다르다
  draft_item         document_item 4712 · status "yielded" · missing []
  draft_item         document_item 4713 · status "blank" · missing ["Market"]
```

**상태 넷이 화면에서 다른 말을 한다.**

| 상태 | 뜻 | 화면이 하는 말 |
|---|---|---|
| `blank` | 위키에 재료가 없다 | **"시장 규모를 알려주세요"** ← 여기만 물어본다 |
| `no_needs` | 표지·목차·상위 묶음 | 아무 말도 안 한다 |
| `yielded` | 다른 항목이 그 사실을 맡았다 | **"그 얘기는 2-1 에 썼어요"** |
| `unwritten` | 재료를 받고도 글이 안 나왔다 | 집필 실패다. 이미 준 정보를 또 달라고 하면 안 된다 |

넷을 `blank` 하나로 뭉치면 화면이 목차를 가리키며 "알려주세요"라고 한다 — 실측에서 못 채움 7 중 3이 그것이었다([`models.py` `DraftItemStatus`](../src/finnect/models.py)).

`yielded_to`("2-1 에 썼어요")는 저장 안 하고 계산한다. **못 받은 항목의 배분은 비어 있어서** 자기가 받은 사실로는 못 찾고, 원했던 자리에서 출발해 그 자리를 누가 받았는지 거꾸로 찾는다([`api/draft_service.py` `_who_took`](../src/finnect/api/draft_service.py)).

## 실행

```
CLI                                          API
─────────────────────────────────────────────────────────────────────
--read-forms 20    ①-a · 양식 20개            (없다 — 운영이 미리 돌린다)
--company --notice ①-b~⑤                     POST …/draft   → 202 · 스레드
                                              GET  …/draft   → running: true
                                              PUT  …/draft/items/{id} → 사람이 고침
```

**세션과 스레드를 3단으로 가른다**([`service.py`](../src/finnect/draft/service.py)) — 조립(세션 안·읽기만) → 호출(세션 밖·8워커) → 저장(세션 안·`ordinal` 순). `Session` 을 LLM 호출 내내 붙잡으면 스레드를 못 얹는다. 항목 하나가 예외를 내도 문자열로 잡아 나머지가 남는다.

`build_draft(writers=...)` 가 인스턴스가 아니라 **만드는 함수**를 받는다 — `Usage.calls += 1` 이 원자적이 아니라 하나를 공유하면 토큰 수가 어긋난다.

**호출 수** (항목 16짜리 양식 하나 기준)

```
①-a  0회   (이미 읽은 양식이다 — needs_decided_by 가 박혀 있다)
①-b  1회   (다투는 사실이 있을 때. 없으면 0)
③    10회  (쓸 자리가 있는 항목만. 재료 0건이면 안 부른다)
⑤    1회
──────────
     12회
```
