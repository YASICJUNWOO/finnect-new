## 형식

```
# ADR-NNNN: 제목

- 상태: 채택됨 | 제안됨 | 미결 | 대체됨(→ NNNN)
- 날짜: YYYY-MM-DD

## 맥락      무엇이 문제였나
## 결정      무엇으로 정했나
## 결과      그래서 무엇이 달라지나. 포기한 것 포함
```

번호는 재사용하지 않는다. 뒤집힌 결정은 지우지 않고 상태를 `대체됨`으로 바꾼다.

## 유실된 결정

원래 `PRD.md` 12장에 D1~D18 결정이 있었으나 **그 문서가 존재하지 않는다.** 이전 문서가 옮겨 적은 12개(D1, D2, D4, D5, D11~D18)만 남았고 그중 화면 관련은 이 ADR들로 승계했다.

**D3, D6~D10 여섯 개는 내용을 알 수 없다.** 필요해지면 복원이 아니라 새로 결정한다. 자세한 것은 [ADR-0001](0001-정본-문서-체계.md).
