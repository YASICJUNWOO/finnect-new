# R 적응을 제품 코드로 옮기기 — 인수인계

2026-08-21 육안 검토 여섯 회차로 시안 여덟이 넷으로 줄었고 **`R 적응`(`r-adaptive.html`)이 선택됐다.**
이 문서는 그것을 `web/` 으로 옮기는 작업의 입력이다. 판단 근거와 대가는 [README](README.md) 에 있다.

> ## ⚠ `r-adaptive.html` 은 지금 제 모습으로 안 뜬다 — 열기 전에 읽을 것
>
> **2026-08-21 옮기는 중에 발견했다. CSS 중괄호가 어긋나 있고, 그래서 이 파일은 어느
> 폭에서도 넓은 화면 레이아웃을 안 그린다.** 브라우저로 열면 1440px 에서도 레일·2단·밴드가
> 전부 없고 행이 94.6px 짜리 세로 스택으로 뜬다 — **고른 R 이 아니라 탈락한 A 에 가깝다.**
>
> 셋이 겹쳐 있다.
>
> 1. **129~133행** — `main { padding-left/right:16px }` 앞에 있던 `@media` 여는 줄이 지워지고
>    닫는 `}` 만 남았다. 그 떠돌이 `}` 를 CSS 파서가 **바로 뒤 `main` 규칙의 선택자로 삼켜서**
>    `max-width:1040px; margin:0 auto; padding:24px 24px 64px` 이 통째로 죽는다.
>    (`«밟은 함정» 2번` 을 고치다 생긴 흔적이다. 좁은 화면 `main` 안여백도 이때 사라졌다.)
> 2. **375행** — `@media (max-width:640px)` 의 닫는 `}` 가 없다. 그래서 그 블록이 파일 끝까지
>    이어지고 **`@media (min-width:1024px)` 가 그 안에 중첩된다** — `640 이하이면서 1024 이상`
>    이라 **영원히 안 맞는다.**
> 3. 같은 이유로 **574~649행의 상세 스타일 전부**(`.h1` · `.prose{max-width:62ch}` · `.dlist` …)가
>    640px 이하에서만 걸린다. 1440px 상세에서 `.prose` 는 `max-width:none` 이다.
>
> **실측(Playwright, 1440×1000):** `.rail` `display:none` · `.tier2` `none` · `.band` `none` ·
> `.menu` `flex`(꺼져야 하는 쪽이 켜져 있다) · `.item` `flex` 94.6px · 보조 글자 16px ·
> `main` 폭 1440(상한 없음) · `.prose` `max-width:none` · `.h1` 32px(UA 기본값).
>
> **위 «실측» 표의 `R 적응 (넓게)` 숫자는 이 파일이 깨지기 전에 잰 값이다.** 지금 파일을
> 다시 재면 그 숫자가 안 나온다. **고친 뒤에 재라.**
>
> **시안의 논지는 이 결함과 무관하다.** 무엇을 만들 것인지는 이 문서와 파일 안 주석에
> 글로 다 적혀 있고, 옮기는 작업은 그 글을 따랐다. 넓은 화면의 실제 모습을 눈으로 보려면
> **`e-console.html` 을 열어라** — R 의 ≥1024px 은 정의상 E 이고 그 파일은 멀쩡하다.

## 먼저 써야 하는 ADR — 여섯

**전부 현재 DESIGN.md 를 벗어난다. 코드를 고치기 전에 결정을 남긴다**(CLAUDE.md 「결정은 ADR 에 남긴다」).

1. **좌측 레일** — 현재 DESIGN.md 에 사이드바 금지가 **없다**(옛 §5.4 에 있었고 clean-slate 로 빠졌다).
   그런데 `layout.tsx` 주석이 아직 *"§5 가 금지한 다섯 조합의 첫째다"* 라고 인용한다. **그 주석은 어느 쪽으로 정하든 고쳐야 한다.**
2. **서체 IBM Plex Sans KR** — §3 이 "Pretendard 한 벌" 이라고 적었다.
3. **넓은 화면 보조 글자 13px** — §3 이 "본문은 16px 이상" 이라고 적었다. **좁은 화면에서는 16px 이라 위반이 폭에 따라 켜졌다 꺼진다.**
4. **제목 굵기 500** — §3 관측 굵기가 400·600 이고 `tokens.css` 에 500 이 없다. 옛 감사는 500 을 위반으로 짚었다.
5. **격자 카드 테두리** — §4 «목록» 이 "카드 테두리·채움·그림자가 하나도 관측되지 않았다" 고 적었다.
   **피할 수 없다** — 크롬 없이 만들면 격자로 안 보이고 격자로 보이게 하면 어긴다.
6. **브레이크포인트 1024 · 640px** — §5 가 브레이크포인트를 정한 적이 없다. 근거는 "레일 60 + 콘텐츠 992" 산수뿐이다.

## 시안 선택과 무관하게 걸려 있는 것 둘

현행 화면이 지금 DESIGN.md 를 어긴다. **R 을 안 쓰더라도 고쳐야 한다.**

- 본문 최소 **13px**(§3 은 16px 이상)
- 상세 본문 최장 줄 **74ch**(§5 는 62ch 이하) — `.prose` 에 `max-width: 62ch` 를 걸면 55ch 로 내려간다

---

## 밟은 함정 여섯 — 다시 밟지 말 것

1. **`main` 이 그리드의 직접 자식이면 `margin: 0 auto` 가 `justify-self: stretch` 를 덮고 shrink-to-fit 이 된다.**
   1,369px 칸에서 713px 로 쪼그라들고 `max-width` 가 아예 안 걸렸다. `width: 100%` 를 같이 준다.
2. **미디어쿼리를 기본 규칙보다 앞에 두면 뒤의 shorthand 가 덮는다.** `@media` 안 `padding-left` 를
   뒤의 `padding: 24px 24px 64px` 이 지운다. 좁은 화면 규칙은 **기본 규칙 뒤에** 둔다.
3. **좁은 화면은 넓은 화면 CSS 를 "안 쓰면 되는" 게 아니라 제 규칙을 가져야 한다.**
   4열 마크업을 좁은 화면에서 그냥 flex 로 뒀더니 행이 **279px** 로 터졌다(→ `flex-wrap` + `order` 로 117px).
4. **`.org` 에 ellipsis 를 안 걸면 92px 칸에서 두 줄로 접혀 행이 39 → 57px(+46%) 이 된다.**
   좁은 화면에서는 접히는 게 맞으므로 **넓은 화면에만** 건다.
5. **숨기는 요소의 구분점은 그 요소 안에 넣는다.** `기관 · <span class="src">출처</span>` 로 두고
   `.src` 를 숨기면 `"성남산업진흥원 ·"` 처럼 점만 남는다.
6. **`document.fonts.check()` 를 믿지 않는다.** Wanted Sans 가 없는 문서에서도 `true` 를 준다.
   서체 로드 판정은 **같은 문자열의 렌더 폭 대조**로 한다 — 시스템 대체는 410.45px 라 확연히 다르다.

## 레포 제약 — 어기면 조용히 깨진다

- **`AXES` 배열 하나를 상단 막대와 하단 탭 바가 같이 읽는다. 두 곳에 적지 않는다**(`layout.tsx`).
  R 은 레일과 상단 바가 같은 배열을 읽어야 하고, **한쪽은 반드시 꺼져야 한다** — 같은 메뉴가 화면에 두 번 있으면 안 된다.
- **컴포넌트에 색 리터럴을 쓰지 않는다.** `plan/09` 검증이 grep 으로 본다. 값은 `tokens.css` 에만 있다.
- **`tokens.css` 가 값의 유일한 자리이고 정본은 `DESIGN.md` 다.** 값을 고칠 일이 생기면 DESIGN.md 를 먼저 고친다.
- **`viewportFit: "cover"` 를 지우면 안전영역이 조용히 0 이 된다.** 로컬에서는 멀쩡해 보이고 노치 기기에서만 틀린다.
- 화면 카피는 **해요체**.
