# plan/10 — 읽기 경로를 Vercel에 올린다

> 상태: **막힘** (2026-08-17) — 산출물은 다 만들었고 **Vercel 자격 증명이 없어 실행을 못 했다.** 아래 "막힌 것" 참고
> 종류: 슬라이스 (S4·S5 배포)
> 선행: [09](09-사용자-앱-분리.md)
> 결정: [ADR-0026](../adr/0026-읽기-경로만-vercel에-올린다.md)
> 절차: [`docs/deploy.md`](../deploy.md)

**[plan/09](09-사용자-앱-분리.md)가 "배포하지 않는다. 로컬까지다"로 닫아 둔 것을 이어받는다.**

---

## 목표

공고 목록(S4)과 상세(S5)가 **공개 URL에서 뜬다.** 수집·해독·운영 도구는 로컬에 그대로 남는다.

---

## 왜 지금인가

[ADR-0023](../adr/0023-제품-프론트를-nextjs로-분리한다.md)이 "프론트를 따로 배포할 수 있는 상태가 된다"고 해 두고 위치는 안 정했다. plan/README가 적었듯 **마감이 있고 MVP 완성도가 30점으로 가장 크며 시연이 필수다**([`SPEC.md`](../SPEC.md) §1.5). 시연 URL이 필요하다.

---

## 올리는 것과 안 올리는 것

**이 갈라짐이 이 계획의 전부다.** 이 저장소가 서버리스에 안 맞는 이유 셋은 전부 **쓰기 경로**의 것이다.

| 안 맞는 이유 | 어디 것인가 |
|---|---|
| 첨부 원본 1.7GB가 로컬 디스크에 산다 | `attach` CLI |
| 수집이 응답보다 오래 산다 (149회 · 데몬 스레드 · 30분) | `ingest`·`attach` CLI |
| 기업마당 인증키가 신청한 IP에 묶일 수 있다 | `ingest` CLI |

**읽기 경로는 하나도 해당하지 않는다.** 읽기 전용 2엔드포인트이고 파일을 안 쓰며 오래 도는 것이 없다.

| 올린다 | 안 올린다 |
|---|---|
| `web/` → Vercel `finnect-web` | `python -m finnect.ingest` |
| `src/finnect/api/` → Vercel Python Function `finnect-api` | `python -m finnect.attach` |
| PostgreSQL 74MB → Neon | `src/finnect/admin/` (§6 범위 밖 · 인증 없음) |
| | `data/attachments/` 원본 1.7GB |

---

## 안 하는 것

- **Production 승격을 안 한다.** Preview까지다. 도메인도 안 붙인다
- **인증키를 Vercel에 안 넣는다.** 배포본은 수집을 안 한다
- **첨부 원본을 안 올린다.** 화면은 메타와 해독 상태만 쓰고 파일 링크는 출처 원본을 가리킨다
- **자동 재수집을 안 만든다.** 배포본은 스냅숏이고 갱신은 수동이다. 큐·워커는 [ADR-0021](../adr/0021-인프라-선정을-미룬다.md) B가 미뤄 둔 결정이다

## 막힌 것

**이 세션에 Vercel 자격 증명이 없다.**

| 무엇 | 상태 |
|---|---|
| Vercel MCP | **토큰 만료.** 세션 시작 때는 붙었고(팀 `yasicjunwoos-projects`) 작업 중에 만료됐다 |
| `vercel` CLI | 안 깔려 있다 |
| `~/.vercel` | 없다. CLI 로그인 기록이 없다 |
| `VERCEL_TOKEN` 환경변수 | 없다 |

**이 세션은 비대화형이라 OAuth 흐름을 탈 수 없다.** 재인증은 사람이 해야 한다 — MCP는 `/mcp`, CLI는 `vercel login`이다.

**그래서 T-0028만 닫혔다.** 나머지 셋은 자격 증명이 생기면 [`docs/deploy.md`](../deploy.md)를 따라 순서대로 돌리면 된다.

## 검증

배포 뒤에 돌린다. **전부 미실행이다.**

```bash
curl -s '<API URL>/api/notices' | head -c 200
psql '<Neon URL>' -c 'select source, count(*) from notice group by source'
```

- [ ] API가 공고를 낸다. 기본 응답에 마감된 공고가 없다
- [ ] `notice`가 **31,327건**이다 (1,538 · 29,789)
- [ ] 화면에서 목록 → 상세 → 원문까지 간다
- [ ] 첨부 링크가 **출처 원본**을 가리킨다. 우리 스토리지가 아니다
- [ ] 두 프로젝트에 Vercel Authentication이 켜져 있다
- [ ] 로그인 안 한 브라우저에서 두 URL 다 막힌다
