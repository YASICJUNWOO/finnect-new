# ADR-0021: 저장소·큐·파서를 지금 정하지 않고, 각 항목이 필요해지는 작업에서 정한다

- 상태: 채택됨
- 날짜: 2026-08-17
- 다루는 것: [`SPEC.md` §9](../SPEC.md) 미결 7번 — [`설계정리_개발논의용.md`](evidence/2026-08-16-v2-기획문서/설계정리_개발논의용.md) §7의 미결 8건(A~H)
- 고치는 것: [plan/README](../plan/README.md)의 "막혀 있는 것"

## 맥락

`SPEC.md` §9-7이 오브젝트 스토리지·큐·워커·벡터 저장·HWP 파서·OCR·ETL 주기·비용·격리 정책을 한 덩어리 미결로 묶어 두었고, [plan/README](../plan/README.md)가 그것을 **"F1-1 전체. 아무것도 시작 못 한다"**로 적었다.

**그 문장이 사실이 아니다.** 여덟 항목은 전부 아직 존재하지 않는 코드의 것이다.

- 오브젝트 스토리지가 필요한 시점은 파일을 받을 때다. **지금 받지 않는다.** 첨부는 메타데이터만 담는다
- 큐와 워커가 필요한 시점은 요청 안에서 안 끝나는 작업이 생길 때다. 지금 그런 작업이 없다
- 벡터 저장이 필요한 시점은 근거 청크를 검색할 때다. **LLM을 아직 한 번도 부르지 않았다**
- HWP 파서는 **되는 것이 이미 확인됐다** — 추출률 95%, HWP·HWPX·DOCX 100%([실측](evidence/2026-08-16-첨부파싱-배점실측.md)). 남은 것은 라이브러리 선정이고 그건 파싱을 시작할 때 고른다

레포는 이미 같은 원칙을 갖고 있다. **"틀린 문서를 미리 쓰지 않는다."** 계층별 상세 사양을 코퍼스를 보고 나서 쓰기로 한 것과([ADR-0009](0009-구-백엔드-재사용-보류.md)) 같은 이유가 인프라 선정에도 적용된다. 지금 고르면 고른 근거가 코드가 아니라 추측이 된다.

## 결정

**여덟 항목을 지금 정하지 않는다.** 각 항목은 그것을 실제로 필요로 하는 작업이 시작될 때, 그 작업 안에서 정하고 ADR로 남긴다.

| # | 안건 | 언제 정하나 |
|---|------|------------|
| A | 저장소 구성 · 벡터 저장 위치 | 원본 파일을 처음 받을 때(F1-1). **벡터는 따로 본다** — 근거 청크 검색을 처음 붙일 때고, 그전에 PostgreSQL로 되는지부터 확인한다 |
| B | 큐 · 워커 스택 | 처리가 요청 안에서 안 끝나는 것이 **측정으로** 확인될 때 |
| C | HWP 파서 · OCR · 표 추출 | 첨부 파싱(F2-2)을 시작할 때. 후보와 추출률은 이미 실측이 있다 |
| D | 공고 ETL 소스 · 주기 | **부분적으로 이미 정해졌다.** 소스 둘과 사람이 누르는 실행은 [ADR-0011](0011-수집-실행-화면.md)이다. 주기 자동화는 사람이 누르는 것이 실제로 불편해질 때 |
| E | 그래프 저장 형태 | 노드 스키마를 쓸 때. 그건 코퍼스를 보고 쓴다 |
| F | RAG 도입 시점 | 집필(F6)에 들어갈 때 |
| G | LLM 비용 · 지연 | LLM 제공자를 정할 때 함께. 아직 한 번도 안 불렀다 |
| H | 개인정보 · 격리 | 사용자 문서를 처음 저장할 때(F1-1) |

**그때까지의 최소 MVP는 수집과 조회다.** 지금 돌아가는 것이 그것이고, 여기에는 여덟 항목이 하나도 필요하지 않다.

## 결과

- **plan/README의 "아무것도 시작 못 한다"가 틀린 문장이 된다.** 같은 커밋에서 고친다.
- `SPEC.md` §9의 7번이 미결 목록에서 내려간다. **미결이 아니라 미룬 결정이다.** 둘은 다르다 — 미결은 답을 모르는 것이고, 이건 답할 때가 아직 아닌 것이다.
- **A와 H가 같은 시점(F1-1)에 걸린다.** 파일을 처음 받는 작업이 저장 위치와 격리 정책을 함께 정하게 된다. 나눠서 정할 수 없다.
- **포기한 것 — 아키텍처 전체 그림을 미리 못 본다.** 나중에 고른 조각들이 서로 안 맞을 수 있다. 특히 A(저장소)와 B(큐)는 보통 같이 고르는 축이라 **B를 나중에 정하면 A를 다시 볼 가능성이 있다.** 그 대가를 알고 받는다.
- 되돌리는 조건: **두 항목 이상이 서로를 기다려 아무것도 시작 못 하는 상태가 실제로 오면**, 그때 한꺼번에 정한다. 지금은 그 상태가 아니다.
